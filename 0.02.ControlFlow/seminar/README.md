# Семинар 2. Условия, циклы и файлы вблизи

Семинар к лекции 2: что на самом деле возвращают `and` и `or`, где `any` и `all`
обманывают, почему цикл пропускает элементы при удалении из списка, почему
`match` иногда подходит ко всему подряд, почему второе чтение файла возвращает
пустоту и откуда `import` берёт модули.

Теория — в `Seminar2.ipynb`.

## Задачи

Лежат в `problems`. В CI они **не проверяются** и на баллы не влияют: решение
показывается преподавателю на семинаре вместе с зелёным прогоном тестов.

```
cd 0.02.ControlFlow/seminar/problems
python3 -m pytest
```

Порядок — от простого к сложному:

1. `defaults.py` — значения по умолчанию и границы;
2. `checks.py` — проверки через `any` и `all`, без переменной-флага;
3. `cleanup.py` — списковые включения вместо изменения списка на ходу;
4. `shapes.py` — разбор данных через `match` с ограничителями;
5. `logfile.py` — чтение и запись файлов.

Разрешено всё из лекций 1–2 и всё, что разобрано в ноутбуках обоих семинаров.
Множества, словари и сортировка — тема следующей лекции, они здесь не нужны.

Успеть на паре все пять задач не обязательно: непройденное разбирается в начале
следующего семинара.
