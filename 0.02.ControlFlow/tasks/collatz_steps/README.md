# collatz_steps

Последовательность Коллатца строится так: чётное число делится на 2, нечётное
умножается на 3 и увеличивается на 1. Процесс повторяется, пока не получится
единица.

Реализовать функцию `collatz_steps(n: int) -> int`, возвращающую количество
шагов, за которое `n` превращается в единицу.

## Сигнатура

```python
def collatz_steps(n: int) -> int: ...
```

## Примеры

```python
collatz_steps(1)  # 0
collatz_steps(2)  # 1   2 -> 1
collatz_steps(3)  # 7   3 -> 10 -> 5 -> 16 -> 8 -> 4 -> 2 -> 1
collatz_steps(16)  # 4
```

Аргумент — целое число не меньше единицы.
