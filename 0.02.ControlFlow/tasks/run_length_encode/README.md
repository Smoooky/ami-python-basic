# run_length_encode

Кодирование длин серий (RLE) — простейший способ сжатия. Идея в том, что
подряд идущие одинаковые символы выгоднее записать один раз, добавив к ним
число повторений: вместо `aaaa` — `a4`.

Такое кодирование хорошо работает там, где длинные серии естественны:
чёрно-белые изображения, где подряд идут десятки одинаковых пикселей, или
результаты измерений с долгими периодами без изменений. На обычном тексте оно,
наоборот, чаще удлиняет запись — в слове `текст` серий нет, и каждый символ
получает бесполезную единицу.

## Серии

Серия — это максимальный кусок строки из одинаковых символов. Важно, что серии
считаются только по соседним символам: строка разбивается на серии слева
направо, а одинаковые символы в разных местах строки в одну серию не
объединяются.

Например, строка `aaabbca` разбивается так:

| Серия | Символ | Длина |
|---|---|---|
| `aaa` | `a` | 3 |
| `bb` | `b` | 2 |
| `c` | `c` | 1 |
| `a` | `a` | 1 |

Последняя серия — снова `a`, но она отдельная: между ней и первой стоят другие
символы. Результат кодирования — `a3b2c1a1`.

## Задача

Реализовать функцию `run_length_encode(text: str) -> str`, возвращающую
RLE-запись строки: для каждой серии подряд сам символ, затем её длина.

## Сигнатура

```python
def run_length_encode(text: str) -> str: ...
```

## Примеры

```python
run_length_encode("aaabbc")  # "a3b2c1"
run_length_encode("aaabbca")  # "a3b2c1a1"
run_length_encode("abc")  # "a1b1c1"
run_length_encode("a")  # "a1"
run_length_encode("")  # ""
```

Длина указывается всегда, даже для серии из одного символа. Пустая строка даёт
пустую строку. Символы могут быть любыми, включая пробелы и цифры.
