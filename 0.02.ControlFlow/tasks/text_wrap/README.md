# text_wrap

Перенос текста по ширине — то, что делает любой редактор, показывая абзац в
окне: текст разбивается на строки не длиннее заданного числа символов, причём
слова не разрываются. Та же задача возникает при выводе в терминал и при
подготовке текста к печати.

## Правила разбиения

Текст разбивается на слова по пробельным символам; исходное расположение
пробелов и переводов строк значения не имеет. Затем слова собираются в строки
по порядку:

* слова в строке разделяются **одним** пробелом;
* длина строки не должна превышать `width` символов;
* следующее слово добавляется в текущую строку, если после добавления она
  по-прежнему помещается в `width`; иначе начинается новая строка.

Такое разбиение называют жадным: решение принимается для каждого слова
отдельно, без попыток посмотреть вперёд и сбалансировать строки.

## Слово длиннее ширины

Слово не разрывается никогда — даже если само по себе длиннее `width`. Оно
занимает отдельную строку, которая оказывается длиннее заданной ширины. Это
осознанный компромисс: разорванное слово читать хуже, чем строку с превышением.

## Пример

Текст `"один два три четыре"` при `width = 9`:

| Строка | Длина | Почему так |
|---|---|---|
| `один два` | 8 | добавить `три` — стало бы 12 |
| `три` | 3 | добавить `четыре` — стало бы 10 |
| `четыре` | 6 | конец текста |

Результат — `["один два", "три", "четыре"]`.

## Задача

Реализовать функцию `text_wrap(text: str, width: int) -> list[str]`,
возвращающую список строк по правилам выше.

## Сигнатура

```python
def text_wrap(text: str, width: int) -> list[str]: ...
```

## Примеры

```python
text_wrap("один два три четыре", 9)  # ["один два", "три", "четыре"]
text_wrap("a b c", 5)  # ["a b c"]
text_wrap("a b c", 1)  # ["a", "b", "c"]
text_wrap("длинноеслово", 3)  # ["длинноеслово"]
text_wrap("", 10)  # []
text_wrap("   ", 10)  # []
```

Текст без слов даёт пустой список. Ширина — целое число не меньше единицы.
Пустых строк в результате быть не должно.
