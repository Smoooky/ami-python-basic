# fizzbuzz

Реализовать функцию `fizzbuzz(n: int) -> list[str]`, возвращающую список из `n`
элементов для чисел от `1` до `n` включительно по правилам:

* число делится на 3 и на 5 — строка `"FizzBuzz"`;
* делится только на 3 — `"Fizz"`;
* делится только на 5 — `"Buzz"`;
* иначе — само число, записанное строкой.

## Сигнатура

```python
def fizzbuzz(n: int) -> list[str]: ...
```

## Примеры

```python
fizzbuzz(5)  # ["1", "2", "Fizz", "4", "Buzz"]
fizzbuzz(15)[-1]  # "FizzBuzz"
fizzbuzz(0)  # []
```

Все элементы списка — строки, включая числа.
