# even_squares

Реализовать функцию `even_squares(n: int) -> list[int]`, возвращающую квадраты
чётных чисел от `0` до `n` не включительно, в порядке возрастания.

## Сигнатура

```python
def even_squares(n: int) -> list[int]: ...
```

## Примеры

```python
even_squares(10)  # [0, 4, 16, 36, 64]
even_squares(1)  # [0]
even_squares(0)  # []
```

Аргумент неотрицателен.
