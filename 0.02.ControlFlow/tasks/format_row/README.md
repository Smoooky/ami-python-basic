# format_row

Реализовать функцию `format_row(name: str, score: float) -> str`, собирающую
строку таблицы фиксированной ширины:

* имя занимает 12 символов и прижато к левому краю;
* оценка занимает 8 символов, прижата к правому краю и печатается с двумя
  знаками после точки.

Итоговая длина строки — 20 символов, если имя не длиннее 12.

## Сигнатура

```python
def format_row(name: str, score: float) -> str: ...
```

## Примеры

```python
format_row("Alice", 9.5)  # "Alice           9.50"
format_row("Bob", 10)  # "Bob            10.00"
format_row("", 0)  # "                0.00"
```

Если имя длиннее 12 символов, оно не обрезается — строка просто становится
длиннее.
