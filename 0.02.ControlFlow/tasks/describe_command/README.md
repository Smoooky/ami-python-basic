# describe_command

Многие программы принимают команды текстом: строка разбивается на слова, первое
слово задаёт действие, остальные — его аргументы. Так устроены командные
оболочки, консоли отладчиков, чат-боты и внутриигровые консоли.

Разбор такой строки — типичная задача для сопоставления с образцом: нас
интересует не столько конкретное значение, сколько **форма** введённого:
сколько слов, какое первое, есть ли остаток.

## Грамматика

Строка разбивается на слова по пробельным символам. Распознаются четыре формы:

| Форма | Ответ |
|---|---|
| нет слов | `"пустая команда"` |
| одно слово `quit` | `"выход"` |
| три слова: `move`, затем два аргумента | `"движение в (X, Y)"` |
| первое слово `say`, дальше сколько угодно слов | `"сообщение: <остальные слова>"` |
| всё остальное | `"неизвестная команда"` |

В ответе для `move` аргументы подставляются как есть, без преобразования в
числа: `move a b` даёт `"движение в (a, b)"`. Для `say` оставшиеся слова
соединяются одним пробелом независимо от того, сколько пробелов было в исходной
строке.

Формы проверяются в указанном порядке, и подходит первая: `move 1 2 3` — это
четыре слова, под форму `move` с двумя аргументами оно не подходит и попадает в
неизвестные.

## Задача

Реализовать функцию `describe_command(line: str) -> str`, возвращающую описание
введённой команды по таблице выше.

## Сигнатура

```python
def describe_command(line: str) -> str: ...
```

## Примеры

```python
describe_command("")  # "пустая команда"
describe_command("   ")  # "пустая команда"
describe_command("quit")  # "выход"
describe_command("move 3 4")  # "движение в (3, 4)"
describe_command("say hello there")  # "сообщение: hello there"
describe_command("say")  # "сообщение: "
describe_command("move 1 2 3")  # "неизвестная команда"
describe_command("quit now")  # "неизвестная команда"
```
