# render_table

Вывод таблицы в консоль — обычная работа для утилит командной строки: `ls -l`,
`docker ps`, `git log --oneline` показывают данные колонками. Ширина колонки не
задаётся заранее: она подбирается под самое длинное значение, иначе таблица
либо расползётся, либо обрежет данные.

## Что должна делать функция

На вход приходит таблица — список строк, каждая строка это список ячеек
(уже строки, приводить ничего не нужно). Первая строка считается заголовком.
Вторым аргументом задаётся выравнивание: по одному символу на колонку.

| Символ | Выравнивание |
|---|---|
| `<` | по левому краю |
| `^` | по центру |
| `>` | по правому краю |

## Как работает выравнивание

Символ выравнивания ставится в спецификации формата перед шириной поля. Строка
дополняется пробелами до этой ширины:

```python
f"{'ab':<6}"  # 'ab    '   прижато влево, пробелы справа
f"{'ab':^6}"  # '  ab  '   по центру, пробелы с обеих сторон
f"{'ab':>6}"  # '    ab'   прижато вправо, пробелы слева
```

Три случая, которые важны для этой задачи.

**Центрирование при нечётном остатке.** Если свободных позиций нечётное число,
поровну разделить их нельзя, и лишний пробел уходит **вправо**:

```python
f"{'ab':^5}"  # ' ab  '    слева один пробел, справа два
f"{'abc':^6}"  # ' abc  '
```

**Ширина меньше содержимого.** Ничего не обрезается — строка выводится целиком,
и поле оказывается шире заданного:

```python
f"{'abcdef':<3}"  # 'abcdef'
```

Именно поэтому ширину колонки нужно считать по самой длинной ячейке: иначе
таблица разъедется, а данные всё равно не обрежутся.

**Выравнивание по умолчанию зависит от типа.** Если символ не указан, строки
прижимаются влево, а числа — вправо:

```python
f"{'x':6}"  # 'x     '
f"{42:6}"  # '    42'
```

В этой задаче все ячейки уже строки, но полагаться на умолчание не стоит:
выравнивание задаётся аргументом и должно применяться явно.

Отдельно обратите внимание на взаимодействие центрирования с требованием
убирать хвостовые пробелы. Ведущие пробелы, добавленные выравниванием, остаются
частью строки:

```python
f"{'ab':^5}".rstrip()  # ' ab'   — ведущий пробел на месте
```

Возвращается список готовых строк вывода:

* ширина каждой колонки равна длине самой длинной ячейки **в этой колонке**,
  считая и заголовок;
* ячейки в строке разделяются ` | ` — пробел, вертикальная черта, пробел;
* сразу после заголовка идёт разделительная линия из дефисов: под каждой
  колонкой дефисов столько же, сколько её ширина, а на месте разделителя
  ячеек — `-+-`;
* хвостовые пробелы в конце каждой строки убираются.

## Ширина колонки известна только во время работы

Спецификация формата после двоеточия — `f"{value:<12}"` — записывается
литералом. Ширина колонки при этом становится известна только после того, как
просмотрены все строки таблицы.

Спецификация не обязана быть литералом: внутри неё разрешены **вложенные поля
подстановки**, и они вычисляются перед тем, как формат применится к значению.
То есть в спецификацию можно подставить и выравнивание, и ширину, вычисленные
во время работы программы.

Второе, что стоит понимать: ширина считается в **символах**, а не в байтах.
Кириллическая ячейка занимает вдвое больше байтов, но выравнивается по числу
символов — как и должно быть для текста на экране.

## Сигнатура

```python
def render_table(rows: list[list[str]], alignments: str) -> list[str]: ...
```

## Примеры

```python
render_table([["имя", "балл"], ["Алиса", "10"], ["Боб", "9"]], "<>")
```

```
имя   | балл
------+-----
Алиса |   10
Боб   |    9
```

```python
render_table([["a"]], "<")
```

```
a
-
```

```python
render_table([], "<")  # []
```

Число символов в `alignments` совпадает с числом колонок, все строки таблицы
имеют одинаковую длину. Пустая таблица даёт пустой список.
