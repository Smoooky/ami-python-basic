# counter

Функция, объявленная внутри другой функции, видит её переменные — и продолжает
их видеть после того, как внешняя функция закончилась. Такую функцию называют
**замыканием**: она «замкнула» на себе кусочек чужой области видимости.

```python
def make_adder(step):
    def add(value):
        return value + step  # step — из внешней функции

    return add
```

Важно, что замыкание держит не *значение*, а **ячейку** с именем. Пока ячейка
одна на всех, все замыкания видят одно и то же — и это то помогает, то ломает
всё. Пример из лекции:

```python
funcs = [lambda: i for i in range(3)]
[f() for f in funcs]  # [2, 2, 2], а не [0, 1, 2]
```

Все три лямбды смотрят в одну ячейку `i`, а к моменту вызова в ней лежит
последнее значение. Чтобы у каждой функции была своя ячейка, её надо создать —
например, вызовом отдельной функции-изготовителя, у которой на каждый вызов
появляется свой набор локальных имён.

Читать имя из внешней функции можно просто так, а вот **менять** — только
объявив `nonlocal`: без него присваивание завело бы новое локальное имя.

## Что реализовать

* `make_counter(start: int = 0) -> Callable[[], int]` — счётчик: каждый вызов
  увеличивает число на единицу и возвращает его. Первый вызов даёт `start + 1`.
  Разные счётчики независимы;
* `make_adder(step: int) -> Callable[[int], int]` — прибавляет `step` к
  переданному числу;
* `make_multiplier(number: int) -> Callable[[int], int]` — умножает на `number`;
* `multipliers(count: int) -> list[Callable[[int], int]]` — список из `count`
  функций: `i`-я умножает на `i`. Наивная запись даст `count` одинаковых
  функций — все на последнее число;
* `shared_counter(count: int) -> list[Callable[[], int]]` — `count` **разных**
  функций, у которых счётчик **один на всех**: сколько бы из них ни вызывали,
  числа идут подряд.

Отрицательное количество в двух последних — `ValueError`.

`multipliers` и `shared_counter` — про одно и то же свойство с двух сторон: в
первом случае общая ячейка мешает и от неё надо избавиться, во втором она и
есть то, что требуется.

## Примеры

```python
step = make_counter()
step(), step(), step()  # 1, 2, 3

another = make_counter(10)
another()  # 11
step()  # 4 — счётчики не мешают друг другу

add_two = make_adder(2)
add_five = make_adder(5)
add_two(7) + add_five(10)  # 24
```

```python
funcs = multipliers(4)
[func(10) for func in funcs]  # [0, 10, 20, 30]
funcs[2](3)  # 6
multipliers(0)  # []

shared = shared_counter(3)
shared[0]()  # 1
shared[1]()  # 2
shared[2]()  # 3
shared[0]()  # 4 — счёт общий
shared[0] is shared[1]  # False — а функции разные
```
