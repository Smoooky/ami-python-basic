# settings

Менеджер контекста — это объект с `__enter__` и `__exit__`; в задачах `capture`
и `rollback` вы писали такие классом. Класс ради двух методов — многовато, и
для простых случаев есть короткая запись: генератор с одним `yield`, помеченный
декоратором `contextlib.contextmanager`.

```python
@contextmanager
def opened():
    print("вход")  # это выполнится в __enter__
    try:
        yield 42  # это уедет в переменную после as
    finally:
        print("выход")  # это выполнится в __exit__
```

Читается так: всё до `yield` — вход в блок, значение из `yield` попадает в
переменную после `as`, всё после `yield` — выход. `try/finally` вокруг `yield`
обязателен: без него хвост не выполнится, если внутри блока что-то упадёт, а
именно ради гарантированного хвоста менеджеры и пишут. Если же вокруг `yield`
поставить `except`, менеджер поймает исключение из блока — и, не пробросив его
дальше, погасит.

## Что реализовать

Три менеджера контекста, все — генераторы с `@contextmanager`.

* `temporary(config: dict[str, Any], key: str, value: Any)` — на время блока
  кладёт в словарь новое значение, а на выходе возвращает всё как было: старое
  значение на место, а если ключа раньше не существовало — удаляет его.
  Через `as` отдаётся **тот же самый** словарь, а не копия. Восстановление
  происходит при любом исходе, в том числе при ошибке внутри блока;
* `section(log: list[str], name: str)` — пишет в журнал `"начало: <name>"` на
  входе и `"конец: <name>"` на выходе. Через `as` не отдаётся ничего;
* `muted(*errors: type[BaseException])` — гасит перечисленные исключения
  (вместе с наследниками) и складывает пойманное в список, который отдаётся
  через `as`. Всё остальное уходит наружу. Без аргументов не гасит ничего.

Различить «ключа не было» и «лежало `None`» по обычной проверке нельзя, поэтому
`temporary` понадобится сторожевой объект из задачи `dig`.

## Примеры

```python
config = {"режим": "обычный", "порт": 80}

with temporary(config, "порт", 8080) as draft:
    draft is config  # True
    config["порт"]  # 8080

config  # {"режим": "обычный", "порт": 80}

with temporary(config, "отладка", True):
    config["отладка"]  # True

"отладка" in config  # False — ключа не было, его и убрали
```

```python
log = []

with section(log, "загрузка"):
    log.append("работаем")

log  # ["начало: загрузка", "работаем", "конец: загрузка"]

with section(log, "разбор"):
    raise RuntimeError("упало")  # ошибка уйдёт наружу,
# ...но "конец: разбор" в журнал уже записан
```

```python
with muted(ValueError) as caught:
    raise ValueError("не страшно")

len(caught)  # 1 — блок закончился, программа работает

with muted(ValueError):
    raise TypeError("а это страшно")  # TypeError уходит наружу
```
