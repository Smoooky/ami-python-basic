# logbook

Отладка часто сводится к одному вопросу: какие функции вызывались, с чем и что
вернули. Дописывать `print` в начало и конец каждой функции — тоскливо и грязно:
строки эти к делу не относятся, а убирать их потом придётся руками.

Обёртка решает это раз и навсегда. Берём функцию, делаем вокруг неё новую,
которая до и после вызова записывает что нужно, и подставляем эту новую под
старым именем:

```python
def traced(func):
    def wrapper(*args, **kwargs):
        ...  # записали
        return func(*args, **kwargs)

    return wrapper


add = traced(add)
```

Строка `@traced` над `def add` — то же самое присваивание, записанное короче.
Так работает любой декоратор: он получает функцию и возвращает то, что встанет
на её место.

У приёма есть плата: на месте функции теперь **другой объект**, и у него своё
имя (`wrapper`) и своя строка документации (пустая). Тот, кто потом попробует
разобраться, увидит в трейсбеке `wrapper` вместо `add`. Лечится это
`functools.wraps` — декоратором, который переносит `__name__`, `__doc__` и
прочие метаданные с исходной функции на обёртку.

Состояние обёртке хранить негде, кроме неё самой, — но функции в Python тоже
объекты, и им можно дописывать атрибуты (PEP 232). Этим и пользуются.

## Что реализовать

* `describe(*args, **kwargs) -> str` — аргументы одной строкой: позиционные
  через `repr`, именованные как `имя=repr`, всё через `", "`. Без аргументов —
  пустая строка;
* `traced(func)` — декоратор. Возвращённая обёртка вызывает исходную функцию,
  передавая ей всё как есть, и сохраняет её метаданные. Кроме того, у обёртки
  есть:
  * `calls: int` — сколько раз её вызвали, считая упавшие вызовы;
  * `history: list[str]` — по записи на вызов: `"имя(аргументы) -> результат"`,
    где результат печатается через `repr`. Если вызов упал, вместо результата
    пишется имя класса исключения, а само исключение уходит наружу;
  * `reset()` — обнуляет счётчик и историю.

Счётчик и история у каждой обёрнутой функции свои.

## Примеры

```python
describe(1, 2)  # "1, 2"
describe(1, b=2)  # "1, b=2"
describe("текст")  # "'текст'"
describe()  # ""
```

```python
@traced
def add(a: int, b: int = 0) -> int:
    """Складывает два числа."""
    return a + b


add.__name__  # "add" — не "wrapper"
add.__doc__  # "Складывает два числа."

add(1, 2)  # 3
add(5)  # 5
add(1, b=2)  # 3

add.calls  # 3
add.history
# ["add(1, 2) -> 3", "add(5) -> 5", "add(1, b=2) -> 3"]

add.reset()
add.calls  # 0

add(1, "два")  # TypeError улетает наружу
add.history  # ["add(1, 'два') -> TypeError"]
add.calls  # 1 — упавший вызов тоже считается
```
