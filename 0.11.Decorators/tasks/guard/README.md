# guard

Декоратор из задачи `logbook` умел ровно одно и всегда одинаково. А хочется
настраивать: не больше **скольких** раз, **какое** значение подставить вместо
ошибки, в **какие** границы уложить результат.

Обычный декоратор получает функцию и возвращает замену. Значит, чтобы принять
ещё и настройки, нужен уровень выше: функция, которая принимает настройки и
возвращает **декоратор**. Три уровня вложенности вместо двух:

```python
def at_most(times):  # принимает настройку
    def decorator(func):  # принимает функцию
        def wrapper(*args, **kwargs):  # принимает аргументы вызова
            ...

        return wrapper

    return decorator
```

Отсюда и разница в записи: `@traced` — сам декоратор, `@at_most(3)` — сначала
вызов, а декоратором становится то, что он вернул. Заодно проверка настроек
происходит в момент вызова `at_most(3)`, то есть при объявлении функции, а не
при первом её вызове.

## Что реализовать

Все три возвращают декоратор и все три сохраняют метаданные обёрнутой функции.

* `at_most(times: int)` — разрешает не больше `times` вызовов; следующий даёт
  `RuntimeError`, в тексте которого есть имя функции. Упавшие вызовы тоже
  считаются потраченными. У обёртки есть атрибут `remaining: int` — сколько
  вызовов осталось. Отрицательное `times` — `ValueError`;
* `default_on_error(value: Any, *errors: type[BaseException])` — ловит
  перечисленные исключения (вместе с наследниками) и возвращает вместо
  результата `value`. Всё, чего в списке нет, улетает наружу. Пустой список
  исключений — `ValueError`;
* `clamped(low: int, high: int)` — прижимает результат к границам: меньше
  `low` становится `low`, больше `high` — `high`. Нижняя граница выше
  верхней — `ValueError`.

`ValueError` в трёх местах выше возбуждается при **создании** декоратора, а не
при вызове обёрнутой функции.

## Примеры

```python
@at_most(2)
def submit(answer: str) -> str:
    """Сдать лабу."""
    return f"принято: {answer}"


submit.__name__  # "submit"
submit.remaining  # 2
submit("раз")  # "принято: раз"
submit("два")  # "принято: два"
submit("три")  # RuntimeError: submit: попытки исчерпаны

at_most(-1)  # ValueError
```

```python
@default_on_error(0, ValueError)
def to_int(text: str) -> int:
    return int(text)


to_int("42")  # 42
to_int("не число")  # 0


@default_on_error("нет", KeyError)
def read(mapping: dict[str, str], key: str) -> str:
    return mapping[key]


read({}, "а")  # "нет"
read(None, "а")  # TypeError — его не ловили
```

```python
@clamped(0, 100)
def score(points: int) -> int:
    return points


score(50)  # 50
score(150)  # 100
score(-20)  # 0
```
