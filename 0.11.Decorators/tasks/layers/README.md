# layers

Декораторы можно класть друг на друга стопкой. Запись

```python
@logged(log)
@doubled
def score(points): ...
```

означает `score = logged(log)(doubled(score))`: применяются они **снизу вверх**,
ближний к `def` первым. От порядка зависит результат, и это не тонкость, а
основная механика: каждый следующий декоратор оборачивает не исходную функцию, а
то, что вернул предыдущий.

В примере выше `logged` смотрит на удвоенный балл, потому что он снаружи. Если
поменять строки местами, он окажется внутри и запишет балл до удвоения. Обе
записи работают, значения в журнале разные.

Отсюда же требование к каждому слою: переносить метаданные через
`functools.wraps`. Слой, который этого не делает, подменяет имя функции на
`wrapper` — и все слои выше начинают видеть в журнале это самое `wrapper`
вместо настоящего имени.

## Что реализовать

Речь про баллы за задачу: удвоить за досрочную сдачу, не выпускать
отрицательное, записать в журнал.

* `logged(log: list[str])` — параметризованный декоратор. Перед вызовом пишет
  `"→ имя(аргументы)"`, после — `"← имя = результат"`. Аргументы печатаются как
  в задаче `logbook`: позиционные через `repr`, именованные как `имя=repr`,
  через `", "`; результат — через `repr`. Если вызов упал, вместо второй
  строки пишется `"× имя: КлассОшибки"`, а исключение уходит наружу;
* `doubled(func)` — удваивает результат;
* `checked(func)` — отрицательный результат превращает в `ValueError`, в тексте
  которого есть имя функции;
* `apply(decorators: Sequence[Decorator], func)` — применить список
  декораторов так же, как это делает стопка `@`: `apply([A, B, C], f)` должно
  дать ровно то же, что `A(B(C(f)))`. Пустой список возвращает функцию как есть.

Все три декоратора сохраняют метаданные, поэтому имя в журнале остаётся
исходным на любой глубине стопки.

## Примеры

```python
above, below = [], []


@logged(above)
@doubled
def first(points: int) -> int:
    return points


@doubled
@logged(below)
def second(points: int) -> int:
    return points


first(5)  # 10
second(5)  # 10

above  # ["→ first(5)", "← first = 10"]
below  # ["→ second(5)", "← second = 5"]
```

```python
log = []


@logged(log)
@checked
@doubled
def score(points: int) -> int:
    return points


score(3)  # 6
score(-1)  # ValueError уходит наружу
log
# ["→ score(3)", "← score = 6", "→ score(-1)", "× score: ValueError"]
```

```python
def plain(points: int) -> int:
    return points


apply([doubled], plain)(4)  # 8
apply([], plain)(4)  # 4
apply([logged(log), doubled], plain)  # то же, что logged(log)(doubled(plain))
```
