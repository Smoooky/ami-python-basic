# Семинар 4. Ссылки вблизи

Семинар к лекции 4: почему `[[0] * 3] * 3` меняется целыми столбцами, чем `+=`
отличается от `+`, зачем нужно присваивание срезу, почему `values =
values.sort()` стирает список, как строка `box[0] += [1]` умудряется
одновременно упасть с ошибкой и сработать и почему `id([]) == id([])` истинно.

Теория — в `Seminar4.ipynb`. Одна ячейка в нём намеренно завершается ошибкой —
это часть разбора.

## Задачи

Лежат в `problems`. В CI они **не проверяются** и на баллы не влияют: решение
показывается преподавателю на семинаре вместе с зелёным прогоном тестов.

```
cd 0.04.References/seminar/problems
python3 -m pytest
```

Порядок — от простого к сложному:

1. `grids.py` — таблица, строки которой не делят один объект;
2. `inplace.py` — изменить на месте или вернуть новый список;
3. `sorting.py` — сортировка и разворот: методом и функцией;
4. `boxes.py` — кортежи с изменяемым содержимым;
5. `copies.py` — поверхностная и глубокая копия руками.

Тесты проверяют не только значения, но и тождество объектов через `is`, поэтому
«вернуть правильный список» бывает недостаточно. Модуль `copy` не нужен нигде.

Успеть на паре все пять задач не обязательно: непройденное разбирается в начале
следующего семинара.
