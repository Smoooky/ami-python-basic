# grid

Матрицу проще всего представить списком строк, а строку — списком чисел. Беда
начинается на первом же шаге, при создании:

```python
matrix = [[0] * 5] * 5
matrix[0][1] = 2
matrix
# [[0, 2, 0, 0, 0],
#  [0, 2, 0, 0, 0],   <- изменили одну клетку, поменялись все строки
#  ...
```

Умножение списка не создаёт пять строк. Оно создаёт список из пяти ссылок на
**одну и ту же** строку — ровно как присваивание не копирует объект. Правильный
способ строит новую строку на каждом обороте цикла:

```python
matrix = [[0] * 5 for _ in range(5)]
```

Внутренний `[0] * 5` здесь безопасен: нули неизменяемы, размножать ссылки на них
не страшно. Опасно размножать ссылки на изменяемые объекты.

## Что реализовать

`Matrix` — список строк одинаковой длины.

* `make(rows, cols, fill=0)` — матрица `rows` на `cols`, заполненная `fill`.
  Все строки должны быть разными объектами. Нулевые и отрицательные размеры
  дают пустую матрицу или пустые строки — отдельно их разбирать не надо,
  `range` и умножение списка справляются сами;
* `is_rectangular(matrix)` — прямоугольная ли матрица: непустая, строки непусты
  и все одной длины;
* `set_cell(matrix, row, col, value)` — записать значение **на месте**, ничего
  не возвращая;
* `row_sums(matrix)` — суммы по строкам;
* `column_sums(matrix)` — суммы по столбцам;
* `transpose(matrix)` — новая матрица, где строки и столбцы поменялись местами.
  Исходная не меняется, и общих строк с ней у результата нет.

Остальные функции считают, что матрица прямоугольная, а индексы клетки внутри
неё. Проверять это они не обязаны — на то есть `is_rectangular`.

## Примеры

```python
make(2, 3)  # [[0, 0, 0], [0, 0, 0]]
make(2, 2, 7)  # [[7, 7], [7, 7]]
make(0, 5)  # []

matrix = make(3, 3)
set_cell(matrix, 0, 0, 5)
matrix  # [[5, 0, 0], [0, 0, 0], [0, 0, 0]] — соседи не тронуты

is_rectangular([[1, 2], [3, 4]])  # True
is_rectangular([[1, 2], [3]])  # False — строки разной длины
is_rectangular([])  # False
```

```python
matrix = [[1, 2, 3], [4, 5, 6]]

row_sums(matrix)  # [6, 15]
column_sums(matrix)  # [5, 7, 9]
transpose(matrix)  # [[1, 4], [2, 5], [3, 6]]
transpose(transpose(matrix)) == matrix  # True
```
