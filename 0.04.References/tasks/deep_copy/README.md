# deep_copy

Поверхностное копирование дублирует только внешний контейнер: вложенные объекты
остаются общими. Глубокое копирование спускается внутрь и копирует всё. В
стандартной библиотеке это `copy.deepcopy`; здесь предстоит написать свою
версию и столкнуться с тем, что делает задачу нетривиальной.

## Что копировать

* списки и словари копируются;
* всё остальное — числа, строки, кортежи, `None` — возвращается как есть: эти
  объекты неизменяемы, и копировать их незачем.

## Сохранение общих ссылок

Если один и тот же список встречается в структуре **дважды**, наивное решение
скопирует его два раза, и в копии окажутся два независимых объекта. Это меняет
поведение структуры: изменение через одну ссылку перестанет быть видно через
другую.

Правильная копия сохраняет отношения: то, что было одним объектом, должно
остаться одним объектом и в копии.

## Циклические ссылки

Список может содержать сам себя — в лекции такой пример разбирался. Наивная
рекурсия на таком входе не завершится. Копия цикла должна остаться циклом:
соответствующее место в копии ссылается на саму копию.

## Как отследить уже скопированное

Ключ здесь — идентичность, а не равенство: два разных списка могут быть равны,
но копировать их нужно порознь. Функция `id` даёт уникальный номер объекта,
пригодный как ключ словаря.

## Сигнатура

```python
def deep_copy(value: Any) -> Any: ...
```

## Примеры

```python
original = [1, [2, 3]]
copy = deep_copy(original)
copy[1].append(4)
original  # [1, [2, 3]] — не изменился

shared = [0]
data = [shared, shared]
result = deep_copy(data)
result[0] is result[1]  # True — общая ссылка сохранена
result[0] is shared  # False — но это уже другой объект

cycle = [1]
cycle.append(cycle)
copy = deep_copy(cycle)
copy[1] is copy  # True
```
