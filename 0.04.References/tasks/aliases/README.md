# aliases

Присваивание в питоне не создаёт коробку со значением. Оно приклеивает к уже
существующему объекту ещё один стикер с именем. Отсюда самое частое недоумение
новичка:

```python
a = [1, 2, 3]
b = a
b.append(4)
a  # [1, 2, 3, 4] — менялся один объект, стикеров на нём два
```

Отличить «один объект под двумя именами» от «два одинаковых объекта» умеет
только `is`: он сравнивает не содержимое, а личность — тот же это объект или
другой. `==` спрашивает про содержимое и на такой вопрос не отвечает.

С числами и строками `is` ведёт себя коварно: интерпретатор заводит маленькие
числа и одинаковые литералы в единственном экземпляре, поэтому `is` на них
часто отвечает `True` — и создаёт ложное впечатление, что так и надо сравнивать.
Не надо: как только числа станут крупнее или появятся из вычисления, ответ
поменяется. `is` уместен только там, где вопрос действительно про личность
объекта: `value is None` и подобное.

## Что реализовать

* `same_object(left, right)` — один ли это объект;
* `same_value(left, right)` — равны ли значения. Ответ — обычный `bool`;
* `describe(left, right)` — словами, одна из трёх строк:
  `"один и тот же объект"`, `"равны, но это разные объекты"`, `"разные"`.
  Проверять надо в этом же порядке: личность важнее равенства;
* `shared_positions(left, right)` — номера позиций, где в обоих списках лежит
  **один и тот же** объект. Равных, но разных объектов тут быть не должно.
  Списки могут быть разной длины — тогда смотрим до конца короткого;
* `distinct_objects(values)` — сколько среди элементов списка различных
  объектов. Пригодится, чтобы поймать матрицу, у которой все строки — одна и
  та же строка.

Ни одна функция ничего не меняет в своих аргументах.

## Примеры

```python
cookie = {"name": "Cookie", "size": "small"}
brownie = cookie  # тот же объект
imposter = {"name": "Cookie", "size": "small"}  # другой, но такой же

same_object(cookie, brownie)  # True
same_object(cookie, imposter)  # False
same_value(cookie, imposter)  # True

describe(cookie, brownie)  # "один и тот же объект"
describe(cookie, imposter)  # "равны, но это разные объекты"
describe(cookie, {"name": "Zoe"})  # "разные"
```

```python
shared = [10, 20]
label = "общая строка"
left = [shared, [1], label]
right = [shared, [2], label]

shared_positions(left, right)  # [0, 2]

row = [0, 0]
distinct_objects([row, row, row])  # 1 — один объект под тремя ссылками
distinct_objects([[0, 0], [0, 0], [0, 0]])  # 3 — три разных списка

distinct_objects([[0] * 3] * 4)  # 1 — так матрицу делать нельзя
distinct_objects([[0] * 3 for _ in range(4)])  # 4 — а так можно
```
