# merge_deep

Настройки программы обычно задаются несколькими слоями: значения по умолчанию,
конфигурация окружения, аргументы запуска. Каждый следующий слой уточняет
предыдущий, и слои вложены — раздел внутри раздела.

Простое слияние словарей здесь не подходит: `{**base, **patch}` заменяет
значение целиком, поэтому вложенный раздел из `patch`, содержащий одну строку,
затрёт весь одноимённый раздел из `base`.

Реализовать функцию
`merge_deep(base: dict[str, Any], patch: dict[str, Any]) -> dict[str, Any]`.

## Правила слияния

* ключ есть только в одном из словарей — попадает в результат как есть;
* ключ есть в обоих, и **оба** значения словари — сливаются рекурсивно;
* ключ есть в обоих, и хотя бы одно значение не словарь — берётся значение из
  `patch`, целиком.

Ни `base`, ни `patch` меняться не должны — это существенно: они принадлежат
вызывающему коду, который продолжит ими пользоваться.

## Сигнатура

```python
def merge_deep(base: dict[str, Any], patch: dict[str, Any]) -> dict[str, Any]: ...
```

## Примеры

```python
merge_deep({"a": 1}, {"b": 2})
# {"a": 1, "b": 2}

merge_deep({"db": {"host": "localhost", "port": 5432}}, {"db": {"port": 5433}})
# {"db": {"host": "localhost", "port": 5433}}

merge_deep({"db": {"host": "localhost"}}, {"db": "off"})
# {"db": "off"}                     значение из patch не словарь — заменяет целиком

merge_deep({"a": {"b": {"c": 1}}}, {"a": {"b": {"d": 2}}})
# {"a": {"b": {"c": 1, "d": 2}}}    сливается на всю глубину
```
