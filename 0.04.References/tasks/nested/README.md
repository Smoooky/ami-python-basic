# nested

Данные не всегда приходят плоскими: список может содержать списки, те — ещё
списки, и так на глубину, которая заранее неизвестна. Циклом такое не обойти —
непонятно, сколько вложенных циклов писать.

Здесь работает рекурсия. Устроена она всегда одинаково и состоит из двух частей:

* **базовый случай** — когда спускаться дальше некуда. Здесь это число: у него
  нет вложенности, и ответ для него очевиден;
* **шаг** — когда есть куда спускаться. Здесь это список: разбираемся с каждым
  элементом тем же способом и складываем ответы.

Базовый случай обязан быть достижим, иначе вызовы не кончатся. В наших данных
это выполняется само: каждый спуск уменьшает глубину, а она конечна.

## Что реализовать

`Data` — это либо число, либо список таких же данных. Циклических ссылок нет:
список не содержит сам себя.

* `total(data)` — сумма всех чисел на любой глубине;
* `depth(data)` — глубина вложенности. У числа она нулевая, у плоского списка —
  единица, у пустого списка тоже единица;
* `flatten(data)` — все числа подряд, слева направо, одним плоским списком;
* `count_lists(data)` — сколько всего списков внутри, считая внешний;
* `find(data, target)` — путь до первого вхождения числа: список номеров, по
  которым надо спускаться. Если числа нет — `None`. Путь до самого значения
  пустой: `find(5, 5)` даёт `[]`.

Обратите внимание: `find` возвращает `None`, когда не нашла, и `[]`, когда
нашла на нулевой глубине. Это разные ответы, и путать их нельзя — проверять
результат надо через `is None`, а не на истинность.

Исходные данные ни одна функция не меняет.

## Примеры

```python
data = [1, [2, [3, 4]], 5]

total(data)  # 15
depth(data)  # 3
flatten(data)  # [1, 2, 3, 4, 5]
count_lists(data)  # 3

total(7)  # 7 — число само себе сумма
depth(7)  # 0
depth([])  # 1
flatten([])  # []
count_lists([])  # 1
```

```python
find(data, 1)  # [0]
find(data, 3)  # [1, 1, 0]
find(data, 99)  # None
find(5, 5)  # []

# по найденному пути можно дойти до значения
path = find(data, 4)  # [1, 1, 1]
place = data
for step in path:
    place = place[step]
place  # 4
```
