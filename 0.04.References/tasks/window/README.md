# window

Срез списка или строки создаёт копию: под неё выделяют память и переписывают
туда данные. Обычно это незаметно, но если взять окно в миллион байт, платить
придётся миллионом байт — даже если посмотреть надо всего один раз.

`memoryview` предлагает другое: не копировать, а смотреть на чужой буфер.
Представление занимает несколько десятков байт независимо от размера окна, а
читается как обычная последовательность.

Плата за это — связь в обе стороны. Изменили буфер — изменилось и то, что видно
через представление. Записали через представление — изменился буфер. Есть и
третье следствие: пока представление живо, размер буфера менять нельзя — он
«экспортирован», и добавить в него байт не выйдет. Знать про это полезно, в
задаче оно не понадобится.

Через представление всегда видно, на чей буфер оно смотрит: у `memoryview` есть
поле `obj` — тот самый объект, к которому оно приставлено.

## Что реализовать

Работаем с `bytearray` — изменяемой последовательностью байтов от 0 до 255.

* `chunk(data, start, size)` — окно на кусок буфера. Возвращается `memoryview`,
  данные не копируются;
* `copy_chunk(data, start, size)` — тот же кусок, но настоящей копией,
  отдельным `bytearray`. Нужна для сравнения: изменения в буфере на неё уже не
  влияют;
* `total(window)` — сумма байтов окна;
* `overwrite(window, values)` — записать значения в окно, изменив тем самым
  исходный буфер. Ничего не возвращает;
* `is_shared(window, data)` — смотрит ли окно именно на этот буфер. Вопрос про
  личность объекта, а не про совпадение содержимого: два буфера с одинаковыми
  байтами — всё равно разные.

Границы окна и длина записываемых значений считаются правильными: `chunk` зовут
с осмысленными `start` и `size`, а `overwrite` — со списком нужной длины и
числами от 0 до 255.

## Примеры

```python
data = bytearray([10, 20, 30, 40, 50])

window = chunk(data, 1, 3)
list(window)  # [20, 30, 40]

data[1] = 99
list(window)  # [99, 30, 40] — окно смотрит на живой буфер

piece = copy_chunk(data, 1, 3)
data[1] = 20
list(piece)  # [99, 30, 40] — копия осталась прежней
```

```python
data = bytearray([10, 20, 30, 40, 50])
overwrite(chunk(data, 1, 3), [1, 2, 3])
list(data)  # [10, 1, 2, 3, 50] — запись прошла в буфер

total(chunk(data, 0, 5))  # 66
```

```python
data = bytearray([1, 2, 3])
other = bytearray([1, 2, 3])  # такой же, но другой объект

is_shared(chunk(data, 0, 2), data)  # True
is_shared(chunk(data, 0, 2), other)  # False

piece = copy_chunk(data, 0, 2)
is_shared(memoryview(piece), data)  # False — копия ни с кем не связана
```
