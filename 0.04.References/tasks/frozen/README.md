# frozen

Кортеж принято называть неизменяемым типом. Это правда, но не вся:

```python
value = (1, 2, [3, 4])
value[2].append(5)
value  # (1, 2, [3, 4, 5])
```

Кортеж действительно не дал заменить свои элементы — все три ссылки остались на
месте. Но третья ссылка ведёт на список, а список менять никто не запрещал.
Неизменяемость кортежа — про сам кортеж, а не про то, что внутри. Такое свойство
и называют **относительной неизменяемостью**.

Отсюда практический вопрос: как понять, что структуру данных точно никто не
испортит? Только спустившись до самого дна и убедившись, что изменяемых частей
там нет.

## Что реализовать

* `is_frozen(value)` — состоит ли значение целиком из неизменяемых частей.
  Числа, строки, `None`, `bytes` — да. Списки, словари, множества,
  `bytearray` — нет. Кортеж — только если неизменяемо всё, что внутри.
  Набор простых типов уже перечислен в заготовке как `ATOMS`;
* `mutable_parts(value, path=())` — пути до изменяемых частей. Путь — кортеж
  номеров: `(2,)` значит «третий элемент», `(1, 1)` — «второй элемент внутри
  второго». Если изменяемо само значение, путь пустой: `[()]`. Внутрь
  изменяемой части заходить не надо — она уже найдена;
* `freeze(value)` — заменить списки кортежами, спускаясь до дна. Кортежи тоже
  обходятся: внутри них могут быть списки. Всё остальное возвращается как есть;
* `thaw(value)` — обратное: кортежи становятся списками.

`freeze` умеет только списки и кортежи. Словарь он вернёт как есть, поэтому
структура со словарём внутри замороженной не станет — и `is_frozen` про неё
честно ответит `False`.

Исходное значение ни одна функция не меняет.

## Примеры

```python
is_frozen(42)  # True
is_frozen((1, (2, 3)))  # True
is_frozen((1, 2, [3, 4]))  # False — дыра внутри кортежа
is_frozen([1, 2])  # False

mutable_parts((1, 2, [3, 4]))  # [(2,)]
mutable_parts((1, [2], [3]))  # [(1,), (2,)]
mutable_parts((1, (2, [3])))  # [(1, 1)]
mutable_parts((1, 2, 3))  # []
mutable_parts([1, 2])  # [()] — изменяемо само значение
```

```python
freeze([1, [2, 3]])  # (1, (2, 3))
is_frozen(freeze([1, [2, 3]]))  # True

thaw((1, (2, 3)))  # [1, [2, 3]]
thaw(freeze([1, [2, [3]]])) == [1, [2, [3]]]  # True

freeze([1, {"a": 1}])  # (1, {'a': 1}) — словарь остался словарём
```
