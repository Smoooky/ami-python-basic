# board

На доске объявлений висят разные бумажки: расписание, объявление кружка,
записка соседу. Устроены они по-разному, но доске от каждой нужно одно и то
же — заголовок и строки текста. Значит, печатать их должна одна общая функция.

Собрать их под общий абстрактный базовый класс не выйдет: часть классов
написали другие люди, и переделывать их вы не можете. Наследование — договор, к
которому надо присоединиться заранее.

`typing.Protocol` — договор, к которому присоединяться не надо. В нём
перечислены методы, и подходит ему любой класс, у которого эти методы есть, —
независимо от того, знал ли его автор о вашем протоколе. Это и называется
**структурной типизацией**: судят по устройству, а не по родословной. В задаче
`notebook` было наоборот: именно пометка о наследовании делала `Section`
тетрадью.

## Что реализовать

* `Pinnable` — протокол с методами `title() -> str` и `lines() -> list[str]`.
  Тел у них нет, только `...`. Протокол нужно пометить `@runtime_checkable`,
  иначе `isinstance` с ним падает с `TypeError`;
* `Note(title: str, text: str)` — записка. `title()` возвращает заголовок как
  есть, `lines()` — непустые строки текста, обрезанные по краям от пробелов.
  **Наследоваться от `Pinnable` нельзя** — в этом весь смысл задачи;
* `render(item: Pinnable) -> str` — заголовок, затем каждая строка с приставкой
  `"- "`, всё склеено переводами строки. Если строк нет — только заголовок;
* `pin_all(items: list[Any]) -> list[str]` — отрендерить те объекты, что
  подходят под протокол, остальные молча пропустить. Порядок исходный;
* `broken_pins(items: list[Any]) -> list[int]` — номера тех, кого `isinstance`
  признал, а `render` обработать не смог: вызов упал с ошибкой. По возрастанию.

Последняя функция нужна потому, что `@runtime_checkable` проверяет только
**наличие имён** — ни сигнатуры, ни даже то, что это вообще методы, `isinstance`
не смотрит:

```python
class Sticker:
    title = "распродажа"  # поле, а не метод
    lines = ["всё по рублю"]


isinstance(Sticker(), Pinnable)  # True — имена-то на месте
render(Sticker())  # TypeError: 'str' object is not callable
```

`pin_all` доверяет `isinstance` и на таком притворщике упадёт. Заметьте и то,
чего `broken_pins` не поймает: объект, чей `lines()` вернёт строку вместо
списка, не упадёт, а выдаст чепуху. Ошибка видна, чепуха — нет.

## Примеры

```python
class Schedule:  # чужой класс, про Pinnable ничего не знает
    def title(self) -> str:
        return "расписание"

    def lines(self) -> list[str]:
        return ["9:00 матан", "10:40 питон"]


note = Note("домашка", "прочитать главу 3\n\n  сдать лабу  ")

note.lines()  # ["прочитать главу 3", "сдать лабу"]
render(note)  # "домашка\n- прочитать главу 3\n- сдать лабу"
render(Note("пусто", ""))  # "пусто"

Pinnable in Note.__mro__  # False — не наследовались
isinstance(note, Pinnable)  # True
isinstance(Schedule(), Pinnable)  # True
isinstance(42, Pinnable)  # False
Pinnable()  # TypeError — протокол не создаётся

pin_all([note, 42, "строка", Schedule()])
# ["домашка\n- прочитать главу 3\n- сдать лабу",
#  "расписание\n- 9:00 матан\n- 10:40 питон"]

broken_pins([note, Sticker(), 42])  # [1]
```
