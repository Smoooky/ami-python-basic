# notebook

В лекции был класс `Tombola` — лотерея. Он ничего не делал сам: объявлял, что у
любой лотереи есть `load` и `pick`, а всё остальное писал через них. Здесь то
же самое, но про записи.

Тетрадь с записями: у каждой есть заголовок и текст. Записи можно прочитать,
переписать, стереть и перечислить — четыре действия, дальше начинаются
различия. Одна тетрадь хранит записи в словаре, другая не хранит ничего: это
раздел внутри чужой тетради. Договор между ними записывают абстрактным базовым
классом: потомок обязан реализовать помеченные методы, иначе объект не
создастся. А раз четыре действия есть у **любой** тетради, всё остальное
пишется один раз в базовом классе — через них, и работает даже с теми
тетрадями, которых ещё нет.

В заготовке уже лежат объявление `Notebook` с четырьмя абстрактными методами
(трогать их не нужно) и готовый класс `PlainNotebook` — образец реализации.

## Что реализовать

### Пять готовых методов в `Notebook`

Пишутся только через четыре абстрактных метода: своего хранилища у базового
класса нет и быть не может.

* `get(self, title: str, default: str | None = None) -> str | None` — текст
  записи или `default`, без исключения;
* `write_many(self, notes: dict[str, str]) -> None`;
* `copy_to(self, other: "Notebook") -> int` — переписать все свои записи в
  другую тетрадь и вернуть их число;
* `__len__`, `__contains__`.

**Переопределять эти пять методов в потомках нельзя** — тесты проверяют, что их
имён нет среди собственных атрибутов `PlainNotebook` и `Section`.

### Класс `Section`

Раздел внутри другой тетради; своего хранилища у него нет. Тетрадь одна на всю
группу, а записей хочется много и у каждого свои — поэтому к заголовкам
приписывают общее начало: `"Аня: домашка"`, `"Боря: домашка"`.

* `__init__(self, inner: Notebook, prefix: str)` — поля `inner` и `prefix`;
* чтение, запись и стирание уходят во внутреннюю тетрадь с заголовком
  `prefix + title`;
* `titles` возвращает заголовки **без** приставки и только те, что с неё
  начинались: чужие записи в этот список попадать не должны.

`Section` — тоже полноценная тетрадь: её можно завернуть ещё раз, а в `copy_to`
передать с любой стороны.

## Примеры

```python
diary = PlainNotebook({"понедельник": "ходил на пары"})

diary.get("вторник", "—")  # "—"
"понедельник" in diary  # True
len(diary)  # 1

diary.write_many({"вторник": "проспал", "среда": "сдал лабу"})
diary.titles()  # ["вторник", "понедельник", "среда"]
diary.erase("вторник")
diary.read("вторник")  # KeyError
```

```python
shared = PlainNotebook()
anya = Section(shared, "Аня: ")
borya = Section(shared, "Боря: ")

anya.write("домашка", "прочитать главу 3")
borya.write("домашка", "доделать лабу")

shared.titles()  # ["Аня: домашка", "Боря: домашка"]
anya.titles()  # ["домашка"]
"домашка" in borya  # True
len(anya)  # 1

my_own = PlainNotebook()
anya.copy_to(my_own)  # 1
my_own.titles()  # ["домашка"]

Notebook()  # TypeError — абстрактный класс
```
