# duck_check

Вы пишете функцию, в которую передают неизвестно что: список, строку, число
или чей-то самодельный класс. Прежде чем начинать работу, хочется понять,
получится ли с этим объектом задуманное. Питон предлагает два способа
спросить, и оба неточные.

**Утиный.** Пробуем сделать то, что хотели, и смотрим, что вышло. Проверка
совпадает с использованием, поэтому соврать она не может. Дешёвый её вариант —
`hasattr(объект, "имя")`: есть ли у объекта атрибут с таким именем, поле или
метод, неважно. Ищется он и в самом объекте, и в классе, и во всех родителях.

```python
hasattr([1, 2], "append")  # True
hasattr([1, 2], "keys")  # False
hasattr([1, 2], "__len__")  # True — dunder-методы тоже атрибуты
```

**Гусиный.** Спрашиваем у объекта, кем он себя считает: `isinstance` вместе с
абстрактными классами из `collections.abc` отвечает, заявлен ли интерфейс. Это
дешевле и позволяет отказать до начала работы, но отвечает не на тот вопрос,
который задавали.

```python
value = (1, 2, [3, 4])
isinstance(value, abc.Hashable)  # True — метод __hash__ у класса есть
hash(value)  # TypeError: unhashable type: 'list'
```

Задача — написать обе проверки и увидеть, где каждая врёт.

## Что реализовать

* `looks_like(value: Any, *names: str) -> bool` — есть ли у объекта все
  перечисленные атрибуты. Без имён — `True`;
* `is_hashable(value: Any) -> bool` — честная проверка: позвать `hash` и
  поймать `TypeError`;
* `abc_names(value: Any) -> set[str]` — имена тех абстрактных классов из
  готового кортежа `CHECKED`, которым объект соответствует по мнению
  `isinstance`. Имя берётся из `__name__`;
* `hash_promise_broken(value: Any) -> bool` — объект, про который `isinstance`
  говорит «хешируемый», а `hash` при этом падает.

Кортеж `CHECKED` уже написан в заготовке, менять его не нужно.

Врёт при этом и утка: `hasattr` смотрит только на имя и не проверяет ни числа
аргументов, ни осмысленности поведения. Класс с методом `__len__`,
возвращающим строку, пройдёт `looks_like` и упадёт на `len()`.

## Примеры

```python
looks_like([1, 2], "__len__", "__getitem__")  # True
looks_like([1, 2], "__len__", "keys")  # False
looks_like(42)  # True

is_hashable(42)  # True
is_hashable([1, 2])  # False
is_hashable((1, 2))  # True
is_hashable((1, 2, [3, 4]))  # False

abc_names([1, 2])
# {"Sized", "Iterable", "Container", "Sequence", "MutableSequence"}
abc_names(42)  # {"Hashable"}
abc_names(print)  # {"Hashable", "Callable"} — функцию можно вызвать

hash_promise_broken((1, 2, [3, 4]))  # True
hash_promise_broken((1, 2, 3))  # False
hash_promise_broken([1, 2])  # False — тут isinstance ничего и не обещал
```
