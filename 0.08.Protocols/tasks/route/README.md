# route

В задаче `playlist` последовательность получилась утиная: работает, но
`isinstance` её не признаёт, `index` и `count` приходится писать руками, а
менять элементы нельзя вовсе. Писать всё это не нужно: `collections.abc`
предлагает сделку — реализуйте небольшой набор методов и объявите об этом
наследованием, а остальное получите готовым. Сделка честная в обе стороны:
абстрактный класс не даст создать объект, пока обязательные методы не написаны,
и упадёт с `TypeError` прямо на `Route()`, а не через неделю в чужом коде.

## Что реализовать

Класс `Route` — маршрут поездки (список остановок по порядку), наследник
`MutableSequence[str]`.

```python
from collections.abc import Iterable, MutableSequence


class Route(MutableSequence[str]): ...
```

* `__init__(self, stops: Iterable[str] = ())`;
* `__len__`, `__getitem__`, `__setitem__`, `__delitem__` — работа по номеру,
  как у списка: отрицательные номера работают, выход за границы даёт
  `IndexError`. Срезы, в отличие от `playlist`, не требуются;
* `insert(self, index: int, value: str)` — вставка перед указанной позицией;
  единственный обязательный метод, который не dunder;
* `__repr__` — `Route(['Москва', 'Тверь'])`.

Название остановки везде обрезается по краям от пробелов; пустое (или из одних
пробелов) недопустимо: `ValueError`. Правило действует и при создании маршрута,
и при любой последующей записи.

## Что приезжает бесплатно

От `Sequence`: `__contains__`, `__iter__`, `__reversed__`, `index`, `count`.
От `MutableSequence`: `append`, `extend`, `pop`, `remove`, `reverse`, `clear`,
`__iadd__`. **Ничего из этого писать нельзя** — тесты проверяют, что этих имён
нет среди собственных атрибутов класса.

Работает это без магии: `append` в `MutableSequence` — это
`self.insert(len(self), value)`, то есть чужой метод зовёт ваш. Отсюда
следствие в обе стороны. Ошибка в `insert` — сразу ошибка в `append`, `extend`
и `+=`. И наоборот: правило, записанное в `insert` один раз, действует везде —
в том числе при создании маршрута, если пустить создание через уже написанные
методы, а не заполнять список напрямую.

## Примеры

```python
route = Route(["  Москва ", "Тверь"])
route  # Route(['Москва', 'Тверь'])
route[0]  # "Москва"

route.append("  Новгород  ")  # не писали, а работает
route[-1]  # "Новгород" — и пробелы обрезались
route.append("   ")  # ValueError
Route(["   "])  # ValueError — правило действует и здесь

route.insert(1, "Клин")
list(route)  # ["Москва", "Клин", "Тверь", "Новгород"]

route.index("Тверь")  # 2
route.count("Москва")  # 1
list(reversed(route))  # ["Новгород", "Тверь", "Клин", "Москва"]

route[0] = " Химки "
route[0]  # "Химки"
del route[0]
route.pop()  # "Новгород"
route += ["Бологое"]
list(route)  # ["Клин", "Тверь", "Бологое"]

isinstance(route, abc.MutableSequence)  # True — теперь признают
```
