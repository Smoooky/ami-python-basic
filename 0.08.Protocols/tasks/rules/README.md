# rules

Лента комментариев проходит через набор правил: слишком короткие не пускаем, с
запрещёнными словами не пускаем, дальше добавится ещё десяток условий. Правило
удобно представить функцией «текст → пропускать ли», и первые два-три правила
действительно пишутся функциями.

А потом выясняется, что порог длины в разных местах разный. Обычная функция
настройки не имеет: придётся либо плодить `longer_than_10` и `longer_than_140`,
либо возвращать функцию из функции. Второе работает, но у замыкания нет ни
имени, ни внятного `repr` — при печати оно выглядит как `<function ... at
0x7f3c>`, и понять, какое правило не пропустило комментарий, невозможно.

Объект с методом `__call__` решает обе беды: настройки лежат в полях, `repr`
пишется как обычно, а для того, кто вызывает, разницы с функцией никакой —
скобки после имени и есть `__call__`.

## Что реализовать

Классы-правила возвращают `True`, если текст правило **прошёл**.

* `Longer(limit: int)` — текст длиннее `limit` символов; `repr` — `Longer(10)`;
* `NoWords(words: list[str])` — в тексте не встречается ни одного из слов.
  Сравнение без учёта регистра и по вхождению подстроки: `"спам"` находится и в
  `"Спамище"`. Список нужно скопировать. `repr` — `NoWords(['спам'])`;
* `is_rule(value: Any) -> bool` — можно ли объект вызвать;
* `broken_rules(text: str, rules: list[Any]) -> list[int]` — номера правил,
  которые текст не прошёл, по возрастанию. Не пройдено — если результат ложен
  по обычным правилам питона;
* `accepted(texts: list[str], rules: list[Any]) -> list[str]` — тексты,
  прошедшие все правила, в исходном порядке.

Правилом может быть что угодно вызываемое: функция, лямбда, объект с
`__call__`. Разбирать, что именно пришло, не нужно и не следует.

Проверять `__call__` через `hasattr` — ошибка: специальные методы питон ищет
**в классе**, минуя словарь самого объекта.

```python
sneaky = Sneaky()  # класс Sneaky пустой
sneaky.__call__ = lambda text: True

hasattr(sneaky, "__call__")  # True — атрибут в словаре объекта есть
callable(sneaky)  # False — а в классе его нет
sneaky("текст")  # TypeError: 'Sneaky' object is not callable
```

Встроенный `callable` спрашивает в правильном месте. Заодно он честно отвечает
`True` про классы: класс — это то, что вызывают, чтобы получить объект.

## Примеры

```python
def not_empty(text: str) -> bool:
    return bool(text.strip())


rules = [not_empty, Longer(10), NoWords(["спам", "реклама"]), lambda t: not t.isupper()]

broken_rules("Отличный разбор, спасибо!", rules)  # []
broken_rules("ок", rules)  # [1]
broken_rules("СПАМ СПАМ КУПИ ПРЯМО СЕЙЧАС", rules)  # [2, 3]
broken_rules("", rules)  # [0, 1]

accepted(["ок", "Отличный разбор, спасибо!", "спам-спам-спам-спам"], rules)
# ["Отличный разбор, спасибо!"]

repr(Longer(10))  # "Longer(10)"
repr(NoWords(["спам"]))  # "NoWords(['спам'])"

is_rule(not_empty)  # True
is_rule(Longer(10))  # True
is_rule(Longer)  # True — класс тоже вызывают
is_rule(42)  # False
```
