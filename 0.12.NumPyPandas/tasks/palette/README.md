# palette

В задаче `picture` картинка была таблицей яркостей. Цветная устроена так же,
только таблиц три — красная, зелёная и синяя, — и лежат они друг на друге.
Получается массив формы `(высота, ширина, 3)`: у каждого пикселя не одно число,
а три.

Работать с третьим измерением помогает `...` (он же `Ellipsis`). Запись
`image[..., 0]` означает «по всем измерениям, кроме последнего, берём всё, а из
последнего — нулевой элемент», то есть красный канал целиком. Для двумерной
картинки то же самое пришлось бы писать `image[:, :, 0]`, и при смене
размерности такая запись сломается, а `...` — нет.

Вторая половина задачи — про склейку. У numpy для неё три функции, и разница
между ними именно в том, какое измерение растёт:

* `hstack` приклеивает сбоку — растёт ширина, ось 1;
* `vstack` приклеивает снизу — растёт высота, ось 0;
* `dstack` кладёт в стопку по глубине — растёт последняя ось, и именно так три
  одноканальные картинки собираются в одну цветную.

## Что реализовать

`Colour` — массив `(высота, ширина, 3)` из `uint8`, `Gray` — двумерный `uint8`.

* `check(image)` и `check_gray(image)` — проверки формы и типа: не тот размер
  или не `uint8` — `ValueError`. Их вызывают все остальные функции;
* `channel(image, number)` — один канал как обычная чёрно-белая картинка.
  Возвращается `view`. Номер не 0, 1 или 2 — `ValueError`;
* `swap_red_and_blue(image)` — поменять местами красный и синий канал, зелёный
  не трогать. Это тоже `view`: разворот последней оси ничего не копирует;
* `from_channels(red, green, blue)` — собрать цветную картинку из трёх
  одноканальных. Разные размеры каналов — `ValueError`;
* `to_gray(image)` — перевести в чёрно-белое: каждый канал со своим весом из
  `LUMA`, результат округляется к ближайшему целому. Веса не равны друг другу
  и в сумме дают единицу, поэтому картинка, у которой все три канала совпадают,
  после перевода не меняется;
* `side_by_side(left, right)` — склеить две картинки по горизонтали. Разная
  высота — `ValueError`;
* `stacked(top, bottom)` — склеить по вертикали. Разная ширина — `ValueError`.

Веса `LUMA` уже заданы в заготовке: 0.299 на красный, 0.587 на зелёный и 0.114
на синий. Числа не выдуманы — глаз различает зелёный лучше остальных, поэтому
зелёный вносит в яркость больше половины.

## Как посмотреть глазами

Рядом лежит `demo.py`. Он рисует картинку с тремя чистыми квадратами и жёлтой
буквой «F», прогоняет её через ваши функции и раскладывает результаты в PNG:

```bash
python demo.py
```

Что смотреть в `demo-*.png`:

* на `demo-channel-red.png` красный квадрат белый, а зелёный и синий чёрные —
  и так для каждого канала;
* на `demo-swapped.png` красный квадрат стал синим, а зелёный не изменился;
* на `demo-gray.png` зелёный квадрат заметно светлее красного, а синий темнее
  всех — те самые веса в действии;
* `demo-side-by-side.png` шире исходника, `demo-stacked.png` — выше;
* `demo-rebuilt.png` обязан совпасть с `demo-source.png` до пикселя.

На оценку `demo.py` не влияет и в проверке не участвует — это инструмент для
вас. PNG он пишет сам, никаких библиотек для этого ставить не нужно.

## Примеры

```python
image = np.array(
    [
        [[255, 0, 0], [0, 255, 0]],
        [[0, 0, 255], [255, 255, 255]],
    ],
    dtype=np.uint8,
)  # красный, зелёный, синий и белый пиксели

image.shape  # (2, 2, 3)
channel(image, RED)  # [[255, 0], [0, 255]]
channel(image, BLUE)  # [[0, 0], [255, 255]]

red = channel(image, RED)
red[0, 0] = 7
image[0, 0, RED]  # 7 — канал это view
```

```python
swap_red_and_blue(image)[0, 0]  # [0, 0, 255] — был красный, стал синий
swap_red_and_blue(swap_red_and_blue(image))  # снова исходная картинка

from_channels(
    np.array([[10, 20]], dtype=np.uint8),
    np.array([[30, 40]], dtype=np.uint8),
    np.array([[50, 60]], dtype=np.uint8),
)[0, 0]  # [10, 30, 50]
```

```python
to_gray(image)  # [[76, 150], [29, 255]]
# чистый зелёный кажется вдвое светлее чистого красного и впятеро — синего

side_by_side(image, image).shape  # (2, 4, 3) — выросла ширина
stacked(image, image).shape  # (4, 2, 3) — выросла высота
side_by_side(image, np.zeros((3, 2, 3), dtype=np.uint8))  # ValueError
```
