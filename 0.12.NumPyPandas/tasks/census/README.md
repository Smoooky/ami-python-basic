# census

Рядом с задачей лежит `global_population_stats_2024.csv` — тот самый файл из
лекции: 192 страны, по восемь чисел на каждую. Доля детей до 14 лет, доля людей
старше 60, плотность населения, население и его разбивка по полу.

Данные настоящие, и ответы получаются осмысленные: самые молодые страны — это
Центральноафриканская Республика и Нигер, самые стареющие — Япония и Италия.
Проверять такие ответы приятно, потому что их можно сверить с тем, что знаешь о
мире.

Из нового по сравнению с лекцией — три вещи, все разобраны в её конце:
производные колонки (`df["новая"] = ...`), `set_index` с последующим `loc` по
названиям вместо номеров и `groupby` с `agg`, который считает по каждой группе
несколько чисел сразу.

## Что реализовать

Имена колонок вынесены в константы модуля — пользуйтесь ими, а не строками.

* `load()` — прочитать CSV, лежащий рядом с модулем. Путь уже собран в `DATA`,
  чтобы задача работала из любого каталога;
* `add_female_share(table)` — **копия** таблицы с новой колонкой `SHARE`: доля
  женщин в процентах. Исходная таблица не меняется;
* `youngest(table, count)` — `count` стран с наибольшей долей детей: таблица из
  двух колонок, страна и доля, по убыванию, с индексом от нуля. Отрицательный
  `count` — `ValueError`;
* `ageing(table, share, population)` — названия стран, где доля людей старше 60
  **больше** `share` и население **больше** `population`, по убыванию доли
  пожилых. Обычный список строк;
* `lookup(table, countries)` — строки по названиям стран, в том порядке, в
  котором их попросили; название страны становится индексом. Неизвестная
  страна — `KeyError`;
* `band(table)` — колонка с полосой плотности: до 50 включительно `"просторно"`,
  до 200 `"средне"`, дальше `"плотно"`. Возвращается `Series` с тем же индексом,
  что у таблицы;
* `summary(table)` — сводка по полосам: сколько стран (`countries`), сколько
  всего людей (`people`) и средняя доля пожилых (`old_share`). Строки
  упорядочены по числу стран, от большего к меньшему.

## Примеры

```python
table = load()
table.shape  # (192, 8)

youngest(table, 3)
#                     Country  Population Aged 0 to 14 (%)
# 0  Central African Republic                         49.0
# 1                     Niger                         46.6
# 2                   Somalia                         46.6

ageing(table, 28.0, 50.0)  # ['Japan', 'Italy', 'Germany', 'France']
```

```python
add_female_share(table).set_index("Country").loc["Russia", "Female share (%)"]
# 53.6

lookup(table, ["Japan", "Russia"])["Population(in millions)"]
# Country
# Japan     123.75
# Russia    144.82

band(table).value_counts()  # средне 84, просторно 57, плотно 51
```

```python
summary(table)
#               countries   people  old_share
# Density band
# средне               84  3539.67      14.37
# просторно            57  1571.38      12.46
# плотно               51  3004.37      15.74
```
