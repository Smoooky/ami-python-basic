# gradebook

Журнал курса — прямоугольная таблица: строка на студента, столбец на работу, в
клетке балл. Почти все вопросы к такой таблице — это «схлопнуть» её по одному
из измерений: средний балл студента считается вдоль строки, средний балл за
работу — вдоль столбца.

За это отвечает аргумент `axis`, и путаются в нём постоянно. Полезно помнить не
«ось 0 — это строки», а **какая ось исчезает**: `table.mean(axis=0)` убирает
измерение студентов, значит остаётся по числу на работу. `axis=1` убирает
работы — остаётся по числу на студента.

Вторая половина задачи — броадкаст. Вычесть из каждой оценки средний балл её
студента в лоб не выйдет: у таблицы форма `(студенты, работы)`, а у средних —
`(студенты,)`, и правило сравнения форм справа налево их не сведёт. Помогает
`keepdims=True`: он оставляет схлопнутую ось длины 1, форма становится
`(студенты, 1)`, и вычитание проходит.

## Что реализовать

`Table` — двумерный массив баллов.

* `check(table)` — общая проверка: не двумерный массив, пустой или с
  отрицательным баллом — `ValueError`. Её вызывают все остальные функции.
  Отрицательные баллы запрещены не из вредности: `scaled` делит на максимум
  столбца, и на отрицательном максимуме порядок перевернулся бы — худшая
  работа получила бы больше ста;
* `student_means(table)` — средний балл каждого студента, вектор длины «число
  студентов»;
* `task_means(table)` — средний балл за каждую работу;
* `centred(table)` — из каждой оценки вычесть средний балл её студента. Форма
  сохраняется, средние по строкам становятся нулями;
* `scaled(table)` — растянуть каждую работу так, чтобы её максимум стал 100.
  Работа, которую никто не решил (весь столбец нули), остаётся нулевой — делить
  на ноль нельзя;
* `best_student(table)` — номер студента с наибольшей **суммой** баллов; при
  равенстве — меньший номер. Ответ — обычный `int`;
* `hardest_task(table)` — номер работы с наименьшим средним баллом; при
  равенстве — меньший номер;
* `passed(table, threshold)` — булев вектор: сдал ли студент **все** работы на
  `threshold` и выше.

Ни одна функция не портит переданную таблицу.

## Примеры

```python
journal = np.array(
    [
        [10.0, 20.0, 30.0, 40.0],
        [40.0, 30.0, 20.0, 10.0],
        [50.0, 50.0, 50.0, 50.0],
    ]
)

student_means(journal)  # [25., 25., 50.]
task_means(journal)  # [33.3, 33.3, 33.3, 33.3]

centred(journal)[0]  # [-15., -5., 5., 15.]
centred(journal).mean(axis=1)  # [0., 0., 0.]

scaled(journal)[:, 0]  # [20., 80., 100.] — по первой работе максимум был 50
scaled(journal).max(axis=0)  # [100., 100., 100., 100.]
```

```python
best_student(journal)  # 2
hardest_task(np.array([[10.0, 1.0], [10.0, 3.0]]))  # 1

passed(journal, 20.0)  # [False, False, True]
passed(journal, 0.0)  # [True, True, True]

student_means(np.array([1.0, 2.0]))  # ValueError — это не таблица
```
