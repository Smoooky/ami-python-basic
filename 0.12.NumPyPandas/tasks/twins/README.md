# twins

На какую страну больше всего похожа Япония? Вопрос звучит как разговорный, но
у него есть честный ответ, если договориться, что значит «похожа». Договоримся
так: у страны есть три числа — доля детей, доля пожилых и число мужчин на сто
женщин, — и похожими считаются страны, у которых эти три числа близки.

Три числа задают точку в трёхмерном пространстве, и вопрос превращается в тот
же, что был в задаче `neighbours`: найти ближайшую точку. Только теперь точки
берутся не из головы, а из настоящей таблицы, и ответы можно сверять со
здравым смыслом.

Есть одна тонкость, без которой ничего не выйдет. Доля пожилых меняется от 3 до
30, а число мужчин на сто женщин — от 84 до 300. Признак с большим разбросом
задавит остальные просто потому, что его числа крупнее. Поэтому признаки
сначала приводят к общему масштабу: из каждого столбца вычитают его среднее и
делят на стандартное отклонение. После этого у каждого столбца среднее 0 и
разброс 1, и все три признака весят одинаково.

## Что реализовать

* `load()` — прочитать CSV, лежащий рядом с модулем;
* `features(table, columns)` — перечисленные колонки как обычный
  `ndarray` из `float64`. Пустой список колонок — `ValueError`, несуществующая
  колонка — `KeyError`;
* `standardize(matrix)` — привести каждый **столбец** к среднему 0 и разбросу 1.
  Столбец, где все значения одинаковы, остаётся нулевым: делить на нулевой
  разброс нельзя. Не двумерный или пустой массив — `ValueError`;
* `distances(matrix)` — матрица попарных расстояний между строками, как в
  `neighbours`, но набор один;
* `most_similar(table, country, count)` — `count` самых похожих стран, от самой
  похожей к менее похожей. Сама страна в ответ не попадает никогда, даже если
  `count` больше числа стран. Неизвестная страна — `KeyError`, отрицательный
  `count` — `ValueError`;
* `odd_one_out(table, countries)` — из списка стран та, что меньше всех похожа
  на остальных: у неё наибольшая сумма расстояний до других стран списка. Меньше
  трёх стран — `ValueError`.

Расстояния считаются по признакам из `FEATURES` и всегда после стандартизации.

## Примеры

```python
table = load()

most_similar(table, "Japan", 5)
# ['Italy', 'Portugal', 'Greece', 'San Marino', 'Germany']

most_similar(table, "Niger", 3)
# ['Mali', 'Somalia', 'Chad']
```

```python
odd_one_out(table, ["Japan", "Italy", "Germany", "Niger"])  # 'Niger'
odd_one_out(table, ["Niger", "Somalia", "Chad", "Japan"])  # 'Japan'
odd_one_out(table, ["Japan", "Italy"])  # ValueError
```

```python
matrix = standardize(features(table, FEATURES))
matrix.mean(axis=0)  # [0., 0., 0.]
matrix.std(axis=0)  # [1., 1., 1.]

distances(matrix).shape  # (192, 192), симметрична, на диагонали нули

standardize(np.array([[1.0, 5.0], [3.0, 5.0]]))
# [[-1., 0.], [1., 0.]] — второй столбец постоянный, его оставили нулевым
```
