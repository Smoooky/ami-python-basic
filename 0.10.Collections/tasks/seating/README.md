# seating

Готовим день первокурсника, и почти в каждом пункте программы надо перебрать
варианты. Сколько получится комбо-обедов из двух супов и трёх вторых? Сколькими
способами четверо встанут на общее фото? Сколько выйдет команд по трое из
группы? Сколько разных стаканчиков мороженого, если шарика два, а вкусов пять?

Все четыре вопроса решаются вложенными циклами, и все четыре — по-разному, а
отличаются они ровно двумя признаками: **важен ли порядок** внутри набора и
**можно ли повторять** элементы. В `itertools` на каждое сочетание признаков
есть своя функция.

| Функция | Порядок важен | Повторы | Пример на «абв» по 2 |
|---|---|---|---|
| `product` | да | да | аа, аб, ав, ба, бб, ... — 9 штук |
| `permutations` | да | нет | аб, ав, ба, бв, ва, вб — 6 штук |
| `combinations` | нет | нет | аб, ав, бв — 3 штуки |
| `combinations_with_replacement` | нет | да | аа, аб, ав, бб, бв, вв — 6 штук |

`product` умеет две формы: `product(a, b)` перебирает пары «элемент из `a`,
элемент из `b`», а `product(a, repeat=n)` — все наборы длины `n` из одного и
того же `a`.

## Что реализовать

Все пять функций возвращают списки, а элементы в них идут в том порядке, в
каком их выдаёт соответствующая функция `itertools`.

* `menus(soups: Sequence[str], mains: Sequence[str]) -> list[tuple[str, str]]` —
  все комбо-обеды «суп плюс второе»;
* `codes(alphabet: str, length: int) -> list[str]` — все коды заданной длины из
  букв алфавита, **строками**, а не кортежами. Отрицательная длина —
  `ValueError`;
* `photos(people: Sequence[str]) -> list[tuple[str, ...]]` — все расстановки
  людей на фото, все сразу встают в кадр;
* `teams(people: Sequence[str], size: int) -> list[tuple[str, ...]]` — все
  команды по `size` человек. Отрицательный размер — `ValueError`;
* `scoops(flavours: Sequence[str], count: int) -> list[tuple[str, ...]]` — все
  стаканчики из `count` шариков; один вкус можно взять несколько раз.
  Отрицательное число шариков — `ValueError`.

Ноль — это не пустой ответ, а один ответ из ничего: `teams(people, 0)` даёт
`[()]`, то есть единственный способ никого не выбрать. Пустой результат — это
`[]`, и он получается, когда набрать нечего: `teams` из троих по четверо.

Одинаковые значения считаются разными элементами: важна позиция в списке, а не
само значение.

## Примеры

```python
menus(["борщ", "уха"], ["плов", "котлета"])
# [("борщ", "плов"), ("борщ", "котлета"), ("уха", "плов"), ("уха", "котлета")]

codes("01", 2)  # ["00", "01", "10", "11"]
len(codes("0123456789", 3))  # 1000 — все трёхзначные коды замка
codes("абв", 0)  # [""]

photos(["Аня", "Боря"])  # [("Аня", "Боря"), ("Боря", "Аня")]
len(photos(["а", "б", "в", "г"]))  # 24
```

```python
teams(["Аня", "Боря", "Вера"], 2)
# [("Аня", "Боря"), ("Аня", "Вера"), ("Боря", "Вера")]
teams(["Аня", "Боря"], 3)  # [] — троих из двоих не набрать
teams(["Аня", "Боря"], 0)  # [()] — единственный способ никого не взять

scoops(["ваниль", "шоколад"], 2)
# [("ваниль", "ваниль"), ("ваниль", "шоколад"), ("шоколад", "шоколад")]
scoops(["ваниль"], 3)  # [("ваниль", "ваниль", "ваниль")]
```
