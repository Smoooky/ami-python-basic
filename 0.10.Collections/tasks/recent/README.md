# recent

В мессенджере сверху висят последние собеседники, в редакторе — недавно
открытые файлы. Список короткий и устроен так: как только вы к чему-то
обращаетесь, оно уезжает наверх, а когда список переполняется, снизу вылетает
то, к чему не обращались дольше всех.

Обычный `dict` с версии 3.7 помнит порядок добавления, и для половины дела
этого хватает. Но «уехать наверх» он не умеет: переложить существующий ключ в
конец можно только удалив и вставив заново. `OrderedDict` из `collections`
делает это одним методом и добавляет ещё один, обратный:

* `move_to_end(key)` — переставить ключ в конец, не трогая значение;
* `popitem(last=False)` — снять и вернуть **первую** пару, то есть самую
  давнюю. С `last=True` (по умолчанию) снимается последняя.

Двух методов достаточно, чтобы собрать вытеснение по давности обращения — то
самое, на котором работает кэш в `functools.lru_cache`.

## Что реализовать

Класс `Recent` — список недавних.

* `__init__(self, capacity: int)` — вместимость; поле `capacity` доступно
  снаружи. Вместимость меньше единицы — `ValueError`;
* `put(self, key: str, value: Any) -> str | None` — добавить или обновить
  запись; в обоих случаях она становится самой свежей. Если список переполнился,
  самая давняя запись выбрасывается, и `put` возвращает её ключ; иначе `None`;
* `get(self, key: str, default: Any = None) -> Any` — значение по ключу.
  Обращение считается: найденная запись становится самой свежей. Если ключа нет,
  возвращается `default` и **ничего не меняется**;
* `forget(self, key: str) -> None` — удалить запись; если такой нет, `KeyError`;
* `keys(self) -> list[str]` — ключи от самого давнего к самому свежему, обычным
  списком;
* `__len__`, `__contains__` и `__repr__` — `Recent(2, ['а'])`.

Проверка через `in` и подсчёт длины обращением **не считаются**: они ничего не
переставляют. Это не придирка — иначе `if key in recent` тихо меняла бы порядок
вытеснения, и список вёл бы себя по-разному в зависимости от того, заглядывали
ли в него по дороге.

## Примеры

```python
chats = Recent(3)
chats.put("Аня", "привет")
chats.put("Боря", "ты где")
chats.put("Вера", "скинь конспект")

chats.keys()  # ["Аня", "Боря", "Вера"] — от давнего к свежему
len(chats)  # 3
"Аня" in chats  # True, и порядок не изменился

chats.put("Гоша", "го в столовую")  # "Аня" — её вытеснили
chats.keys()  # ["Боря", "Вера", "Гоша"]
```

```python
chats = Recent(3)
for name in ("Аня", "Боря", "Вера"):
    chats.put(name, "…")

chats.get("Аня")  # "…", и «Аня» уехала наверх
chats.keys()  # ["Боря", "Вера", "Аня"]
chats.put("Гоша", "…")  # "Боря" — теперь давнее всех она

chats.get("Дима")  # None
chats.get("Дима", "нет")  # "нет", список не изменился
chats.forget("Дима")  # KeyError
```
