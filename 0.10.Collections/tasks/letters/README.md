# letters

Игра в слова: из выданного набора букв нужно собрать слово. Вопросов при этом
всего несколько — хватит ли букв, каких не хватает, не одно ли и то же слово
получилось у двоих, — и все они про **количества букв**, а не про сами слова.

Считать буквы вручную вы уже умеете: словарь плюс цикл. `Counter` из
`collections` — тот же словарь, но заполняющийся сам: `Counter("абракадабра")`
сразу даёт `{"а": 5, "б": 2, ...}`. Отсутствующая буква возвращает `0`, а не
`KeyError`, и при этом в словарь не попадает.

Интереснее другое: счётчики умеют складываться и вычитаться, как множества.
`Counter(слово) - Counter(букв)` — это ровно «чего не хватает», причём лишние
буквы из набора в результат не попадут: отрицательных значений вычитание не
оставляет. А `Counter(слово) <= Counter(букв)` — это «слово собирается»
целиком, одним сравнением.

## Что реализовать

Везде считаются только буквы, регистр не важен: пробелы, знаки препинания и
цифры отбрасываются, `"Ё"` и `"ё"` — одна и та же буква.

* `letter_counts(text: str) -> Counter[str]` — сколько раз встретилась каждая
  буква;
* `top(text: str, count: int) -> list[tuple[str, int]]` — `count` самых частых
  букв парами «буква, сколько». При равном количестве раньше идёт та, что
  встретилась в тексте первой;
* `is_anagram(left: str, right: str) -> bool` — составлены ли два текста из
  одних и тех же букв;
* `can_build(word: str, letters: str) -> bool` — можно ли собрать слово из
  имеющихся букв. Каждая буква набора используется не больше одного раза, так
  что `"мама"` из `"мам"` не собирается;
* `missing(word: str, letters: str) -> Counter[str]` — каких букв и сколько не
  хватает. Если слово собирается, счётчик пустой.

Метод `most_common(n)` отдаёт `n` самых частых пар и при равных количествах
сохраняет порядок первого появления — то есть делает ровно то, что нужно `top`.

## Примеры

```python
letter_counts("абракадабра")  # Counter({"а": 5, "б": 2, "р": 2, "к": 1, "д": 1})
letter_counts("Ало, Алё!")  # то же, что letter_counts("алоалё")
letter_counts("123 ...")  # Counter()

top("абракадабра", 2)  # [("а", 5), ("б", 2)]
top("бав", 3)  # [("б", 1), ("а", 1), ("в", 1)]
top("", 5)  # []
```

```python
is_anagram("апельсин", "спаниель")  # True
is_anagram("Ток", "кот")  # True
is_anagram("кот", "код")  # False

can_build("кот", "тыкво")  # True
can_build("мама", "мам")  # False — второй «а» нет
can_build("", "что угодно")  # True

missing("коток", "кот")  # Counter({"к": 1, "о": 1})
missing("кот", "котлета")  # Counter() — лишние буквы не мешают
missing("мамама", "ма")  # Counter({"м": 2, "а": 2})
```
