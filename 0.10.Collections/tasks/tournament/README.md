# tournament

Турнир по настолкам в общаге: каждый играет с каждым по разу, за победу три
очка, за ничью одно. Нужны расписание, список несыгранного и таблица.

Сыгранный матч — это три значения: кто, с кем и кто выиграл. Кортеж из трёх
элементов хранит их прекрасно, а вот читается потом плохо: `match[2]` не
говорит ни о чём. `NamedTuple` — тот же кортеж, но с именами полей: он
неизменяемый, сравнивается и распаковывается как обычный кортеж, но поля
доступны по именам, а `repr` печатает их вместе со значениями. В лекции
показана функция `namedtuple("Match", [...])`; ниже используется её же вариант
с аннотациями, где типы полей видны сразу:

```python
class Match(NamedTuple):
    left: str
    right: str
    winner: str | None  # None — ничья
```

Остальное собирается из уже знакомых кирпичиков: пары «каждый с каждым» — это
`combinations`, подсчёт очков — счётчик, а места — обычная сортировка.

## Что реализовать

Класс `Match` уже объявлен в заготовке, менять его не нужно.

* `schedule(players: Sequence[str]) -> list[tuple[str, str]]` — все пары,
  каждый с каждым по одному разу, в порядке, который даёт `combinations`;
* `missing(players: Sequence[str], played: Iterable[Match]) -> list[tuple[str, str]]` —
  какие пары ещё не сыграли, в том же порядке. Порядок имён внутри пары не
  важен: матч «Боря — Аня» закрывает пару «Аня — Боря»;
* `standings(players: Sequence[str], played: Iterable[Match]) -> dict[str, int]` —
  очки каждого игрока: победа 3, ничья по 1 обоим, поражение 0. В таблицу
  попадают **все** игроки, в том числе не сыгравшие ни одного матча; порядок
  ключей — как в `players`. Возвращается обычный `dict`;
* `podium(players: Sequence[str], played: Iterable[Match], count: int) -> list[tuple[str, int]]` —
  `count` первых мест парами «имя, очки». Выше тот, у кого больше очков; при
  равенстве — по алфавиту. Отрицательный `count` — `ValueError`.

Матч, в котором победителем записан кто-то посторонний, или матч с игроком не
из турнира — это `ValueError`: молча считать такое нельзя, иначе в таблице
появятся очки из ниоткуда.

## Примеры

```python
players = ["Аня", "Боря", "Вера"]
played = [
    Match("Аня", "Боря", "Аня"),
    Match("Аня", "Вера", None),
]

Match("Аня", "Боря", "Аня").winner  # "Аня"
Match("Аня", "Боря", "Аня") == ("Аня", "Боря", "Аня")  # True

schedule(players)
# [("Аня", "Боря"), ("Аня", "Вера"), ("Боря", "Вера")]

missing(players, played)  # [("Боря", "Вера")]
missing(players, [])  # всё расписание целиком
```

```python
standings(players, played)  # {"Аня": 4, "Боря": 0, "Вера": 1}
standings(players, [])  # {"Аня": 0, "Боря": 0, "Вера": 0}

podium(players, played, 2)  # [("Аня", 4), ("Вера", 1)]
podium(players, played, 100)  # [("Аня", 4), ("Вера", 1), ("Боря", 0)]

standings(players, [Match("Аня", "Боря", "Вера")])  # ValueError
standings(players, [Match("Аня", "Дима", None)])  # ValueError
```
