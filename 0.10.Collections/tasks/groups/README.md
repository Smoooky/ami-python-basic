# groups

Запись в кружки пришла списком пар «кто — куда». Разложить её по кружкам —
дело трёх строк, и первая из них всегда одна и та же: проверить, заводили ли уже
список для этого кружка.

```python
if club not in clubs:
    clubs[club] = []
clubs[club].append(name)
```

Строка служебная, к задаче отношения не имеет, и забыть её — обычное дело.
`defaultdict` из `collections` убирает её насовсем: при обращении к
отсутствующему ключу он сам создаёт значение, позвав переданную ему функцию.
`defaultdict(list)` на новый ключ подставит пустой список, `defaultdict(int)` —
ноль.

Плата за удобство одна, но существенная: **чтение теперь меняет словарь**.
Обращение `clubs["вязание"]` к несуществующему кружку не поднимет `KeyError`, а
молча заведёт пустой список. Поэтому проверять наличие ключа обращением по
квадратным скобкам нельзя — только оператором `in`.

## Что реализовать

* `by_club(pairs: Iterable[tuple[str, str]]) -> defaultdict[str, list[str]]` —
  из пар «имя, кружок» сделать «кружок → список имён». Имена внутри кружка идут
  в порядке появления, кружки — в порядке первого упоминания. Возвращается
  именно `defaultdict`, чтобы к результату можно было дописывать;
* `tally(items: Iterable[str]) -> defaultdict[str, int]` — сколько раз
  встретился каждый элемент;
* `known(mapping: Mapping[str, Any], key: str) -> bool` — есть ли такой ключ.
  Проверка не должна ничего создавать, даже если ей дали `defaultdict`;
* `plain(mapping: Mapping[str, Any]) -> dict[str, Any]` — обычный `dict` с тем
  же содержимым. Отдавать `defaultdict` наружу опасно: получатель не ждёт, что
  чтение будет что-то менять, и `KeyError` у него не сработает.

Функция по умолчанию вызывается **каждый раз заново** — и это важно. Если
вместо `defaultdict(list)` написать `defaultdict(lambda: names)`, где `names` —
готовый список, все ключи получат один и тот же список на всех, и дописывание в
один кружок будет видно во всех остальных.

## Примеры

```python
signups = [
    ("Аня", "робототехника"),
    ("Боря", "театр"),
    ("Вера", "робототехника"),
]

clubs = by_club(signups)
clubs  # {"робототехника": ["Аня", "Вера"], "театр": ["Боря"]}
clubs["вязание"]  # [] — и кружок «вязание» теперь есть в словаре
clubs["вязание"].append("Дима")
clubs["робототехника"]  # ["Аня", "Вера"] — списки независимы
```

```python
counts = tally(["яблоко", "банан", "яблоко"])
counts  # {"яблоко": 2, "банан": 1}
counts["груша"]  # 0

known(counts, "яблоко")  # True
known(counts, "манго")  # False
len(counts)  # 3 — «груша» осталась, «манго» не появилось

result = plain(counts)
type(result)  # dict
result["манго"]  # KeyError
```
