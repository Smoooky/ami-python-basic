# lineup

Считалочка на кухне в общаге: все встают в круг, водящий считает до трёх, и
третий идёт мыть посуду. Потом счёт продолжается со следующего, и так пока
круг не кончится.

Списком такое делается плохо. Убрать человека из середины — это `pop(i)`, а он
сдвигает весь хвост; вставить в начало — `insert(0, x)`, и он сдвигает вообще
всё. Пока людей десять, разницы не видно, но структура для этого просто не
предназначена: список быстр только с правого конца.

`deque` из `collections` — двусторонняя очередь. Добавление и удаление с
**обоих** концов стоят одинаково дёшево: `append` и `pop` справа, `appendleft`
и `popleft` слева. Отдельно есть `rotate(n)` — сдвинуть все элементы по кругу
на `n` позиций вправо (при отрицательном `n` — влево), и `deque(..., maxlen=N)`
— очередь, которая держит только последние `N` элементов и сама выталкивает
лишнее с другого конца.

Из этих двух операций складывается и считалочка (отмотать круг на нужное число
и снять первого), и лента последних событий, и проверка слова-перевёртыша
(сравнивать буквы, снимая их с обоих концов сразу).

## Что реализовать

* `shift(people: Iterable[str], step: int) -> list[str]` — сдвинуть круг на
  `step` позиций вправо. Отрицательный `step` сдвигает влево, слишком большой
  просто проворачивает круг несколько раз;
* `serve(people: Iterable[str], step: int) -> list[str]` — считалочка: по кругу
  отсчитывается `step` человек, и `step`-й выбывает, дальше счёт продолжается со
  следующего за ним. Вернуть выбывших в порядке выбывания. `step` меньше
  единицы — `ValueError`;
* `last(events: Iterable[str], size: int) -> deque[str]` — лента последних
  `size` событий. Возвращается именно `deque` с выставленным `maxlen`, чтобы в
  неё можно было дописывать дальше. Отрицательный размер — `ValueError`;
* `is_palindrome(text: str) -> bool` — читается ли текст одинаково в обе
  стороны. Считаются только буквы, регистр не важен.

Исходный список ни одна из функций не портит.

## Примеры

```python
people = ["Аня", "Боря", "Вера", "Гоша"]

shift(people, 1)  # ["Гоша", "Аня", "Боря", "Вера"]
shift(people, -1)  # ["Боря", "Вера", "Гоша", "Аня"]
shift(people, 5)  # то же, что shift(people, 1)

serve(["Аня", "Боря", "Вера"], 2)  # ["Боря", "Аня", "Вера"]
serve(people, 1)  # ["Аня", "Боря", "Вера", "Гоша"]
serve(people, 0)  # ValueError
```

```python
tape = last(["а", "б", "в", "г"], 2)
list(tape)  # ["в", "г"]
tape.maxlen  # 2
tape.append("д")
list(tape)  # ["г", "д"] — «в» вытеснено само

is_palindrome("шалаш")  # True
is_palindrome("А роза упала на лапу Азора")  # True
is_palindrome("привет")  # False
```
