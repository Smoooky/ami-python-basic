# market_tick

Биржевая лента — поток сделок: инструмент, цена, объём. За торговый день таких
записей десятки миллионов, и они живут в памяти одновременно. Обычный объект
хранит поля в словаре `__dict__`, и на таком количестве записей эти словари
съедают больше памяти, чем сами данные.

Объявление `__slots__` заменяет словарь фиксированным набором ячеек: экземпляр
перестаёт иметь `__dict__`, память сокращается в разы, а присвоение
незаявленного поля — например, из-за опечатки в имени — сразу приводит к
ошибке, вместо того чтобы молча создать новый атрибут.

Реализовать два класса.

## Tick

Запись о цене инструмента.

* слоты `symbol`, `price`, `volume`, других полей у экземпляра быть не должно;
* `__init__(self, symbol: str, price: float, volume: int)`;
* `__repr__` — `Tick('AAPL', 150.25, 100)`;
* равенство по всем трём полям; сравнение с объектом другого типа даёт `False`;
* `notional(self) -> float` — объём сделки в деньгах, произведение цены на
  количество;
* статический метод `from_csv(line: str) -> "Tick"` — разбирает строку вида
  `AAPL,150.25,100`.

## TradeTick

Сделка: та же запись плюс сторона — покупка или продажа.

* собственный слот — только `side`: остальные поля объявлены у родителя;
* `__init__(self, symbol: str, price: float, volume: int, side: str)` —
  остальные поля передаются конструктору родителя. Сторона принимает значения
  `"buy"` и `"sell"`, любое другое недопустимо: `ValueError`;
* `__repr__` — `TradeTick('AAPL', 150.25, 100, 'buy')`;
* равенство: совпадают все поля родителя и сторона. Сделка не равна обычному
  тику с теми же ценой и объёмом;
* `signed_volume(self) -> int` — объём со знаком: положительный для покупки,
  отрицательный для продажи.

## Примеры

```python
tick = Tick("AAPL", 150.25, 100)
tick.notional()  # 15025.0
repr(tick)  # "Tick('AAPL', 150.25, 100)"
Tick.from_csv("AAPL,150.25,100") == tick  # True
tick.prise = 1  # AttributeError: опечатка не пройдёт

trade = TradeTick("AAPL", 150.25, 100, "sell")
trade.signed_volume()  # -100
trade.notional()  # 15025.0 — метод унаследован
trade == tick  # False
TradeTick("AAPL", 1, 1, "hold")  # ValueError

hasattr(tick, "__dict__")  # False
hasattr(trade, "__dict__")  # False
```
