# date_factory

Одна и та же дата приходит в разных форматах: ISO из базы данных, американский
из выгрузки, российский из формы. Разбор каждого формата удобно вынести в
отдельный конструктор, а не превращать `__init__` в разборщик строк.

Реализовать класс `Date`.

## Что реализовать

* `__init__(self, day: int, month: int, year: int)` — сохраняет поля `day`,
  `month`, `year`. Месяц вне диапазона 1–12 и день вне 1–31 недопустимы:
  возбуждается `ValueError`;
* `__str__` — `дд.мм.гггг`, день и месяц всегда двумя цифрами;
* `__repr__` — `Date(day=5, month=3, year=2026)`;
* равенство по всем трём полям; сравнение с объектом другого типа даёт `False`;
* упорядочивание: даты сравниваются хронологически, список дат можно
  отсортировать;
* хешируемость: равные даты имеют равный хеш, дату можно положить в множество;
* статический метод `from_iso(text: str) -> "Date"` — формат `гггг-мм-дд`;
* статический метод `from_american(text: str) -> "Date"` — формат `мм/дд/гггг`;
* `to_iso(self) -> str` — обратное преобразование в `гггг-мм-дд`, все части
  дополняются нулями до нужной длины.

Проверка значений должна работать и при создании через статические методы.

## Примеры

```python
str(Date(5, 3, 2026))  # "05.03.2026"
repr(Date(5, 3, 2026))  # "Date(day=5, month=3, year=2026)"

Date.from_iso("2026-03-05").to_iso()  # "2026-03-05"
Date.from_iso("2026-03-05") == Date.from_american("03/05/2026")  # True
Date(1, 2, 3).to_iso()  # "0003-02-01"

sorted([Date(1, 1, 2027), Date(31, 12, 2026)])
# [Date(day=31, month=12, year=2026), Date(day=1, month=1, year=2027)]

len({Date(1, 1, 2026), Date.from_iso("2026-01-01")})  # 1

Date(32, 1, 2026)  # ValueError
Date.from_iso("2026-13-01")  # ValueError
```
