# money

Денежные суммы не хранят в вещественных числах: двоичная дробь не представляет
десятичные копейки точно, и на длинных расчётах баланс перестаёт сходиться.
Хранят целое число минимальных единиц — копеек, центов — и рядом код валюты.

Из валюты следуют правила арифметики. Складывать рубли с долларами
бессмысленно: курс не зашит в сумму, и результат такого сложения не определён.
Умножать сумму на число можно — это повторение платежа. Умножать сумму на сумму
нельзя: произведение рублей на рубли не является денежной величиной.

Реализовать класс `Money` с полями `amount: int` — количество минимальных
единиц — и `currency: str` — код валюты.

## Операции

| Выражение | Метод | Результат |
|---|---|---|
| `repr(m)` | `__repr__` | `Money(12345, 'RUB')` |
| `str(m)` | `__str__` | `123.45 RUB` |
| `a == b` | `__eq__` | равны сумма и валюта |
| `a < b` | `__lt__` | сравнение сумм одной валюты |
| `a + b`, `a - b` | `__add__`, `__sub__` | новая сумма той же валюты |
| `a += b` | `__iadd__` | изменяет левый операнд, возвращает его же |
| `m * k`, `k * m` | `__mul__`, `__rmul__` | сумма, умноженная на целое число |
| `m *= k` | `__imul__` | изменяет сумму, возвращает её же |
| `-m` | `__neg__` | сумма с противоположным знаком |
| `abs(m)` | `__abs__` | сумма по модулю |
| `bool(m)` | `__bool__` | нулевая сумма ложна, любая другая истинна |
| `hash(m)` | `__hash__` | равные суммы имеют равный хеш |

## Требования к операциям

Сложение и вычитание создают новую сумму и не изменяют операнды. Операции с
присваиванием изменяют левый операнд на месте: переменная после `a += b`
продолжает ссылаться на тот же объект. Такие методы возвращают сам изменённый
объект.

Сложение, вычитание и сравнение сумм **разных валют** не определены: метод
возвращает `NotImplemented`, и язык сообщает об этом ошибкой `TypeError`.
Проверка на равенство — исключение из этого правила: суммы разных валют просто
не равны, ошибки быть не должно.

Умножение определено только на целые числа. Умножение на вещественное число и
на другую денежную сумму не определено.

Строковое представление показывает сумму в основных единицах с двумя знаками:
`Money(12345, "RUB")` печатается как `123.45 RUB`, `Money(-5, "USD")` — как
`-0.05 USD`. Округления здесь нет: сумма хранится целой, деление на сто
выполняется разбором на целую и дробную части.

## Примеры

```python
a = Money(10000, "RUB")
b = Money(2550, "RUB")

str(a)  # "100.00 RUB"
a + b  # Money(12550, 'RUB')
a - b  # Money(7450, 'RUB')
a  # Money(10000, 'RUB') — не изменился
-b  # Money(-2550, 'RUB')
abs(Money(-2550, "RUB"))  # Money(2550, 'RUB')

a += b  # a изменился на месте
m = Money(100, "USD")
m * 3  # Money(300, 'USD')
3 * m  # Money(300, 'USD')
m *= 2  # m изменился на месте

bool(Money(0, "RUB"))  # False
sorted([Money(300, "RUB"), Money(100, "RUB")])  # по возрастанию суммы

Money(100, "RUB") == Money(100, "USD")  # False, ошибки нет
Money(100, "RUB") + Money(100, "USD")  # TypeError
Money(100, "RUB") < Money(100, "USD")  # TypeError
Money(100, "RUB") * 1.5  # TypeError
Money(100, "RUB") * Money(2, "RUB")  # TypeError
```
