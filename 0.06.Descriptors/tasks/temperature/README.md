# temperature

Одна и та же температура записывается в трёх шкалах: Цельсия, Фаренгейта и
Кельвина. Хранить три отдельных поля нельзя — они разъедутся при первом же
изменении. Хранится одно значение, а остальные шкалы вычисляются из него при
чтении и пересчитываются в него при записи.

Реализовать класс `Temperature`. Единственное хранимое поле — температура в
градусах Цельсия; конструктор `__init__(self, celsius: float)` принимает именно
её.

## Что реализовать

Три свойства, каждое доступно и на чтение, и на запись:

| Свойство | Пересчёт из градусов Цельсия |
|---|---|
| `celsius` | значение как есть |
| `fahrenheit` | `celsius * 9 / 5 + 32` |
| `kelvin` | `celsius + 273.15` |

Запись в любое из свойств меняет одно и то же хранимое значение, поэтому
изменение сразу видно во всех трёх шкалах.

Температура ниже абсолютного нуля невозможна: меньше `-273.15 °C`, то есть
меньше `0 K` или `-459.67 °F`. Попытка записать такое значение — через любое из
свойств или в конструкторе — возбуждает `ValueError`. Само значение
абсолютного нуля допустимо.

## Примеры

```python
t = Temperature(100)
t.celsius, t.fahrenheit, t.kelvin  # 100, 212.0, 373.15

t.fahrenheit = 32
t.celsius  # 0.0
t.kelvin  # 273.15

t.kelvin = 0
t.celsius  # -273.15

Temperature(-40).fahrenheit  # -40.0

t.kelvin = -1  # ValueError
t.fahrenheit = -500  # ValueError
Temperature(-300)  # ValueError
```
