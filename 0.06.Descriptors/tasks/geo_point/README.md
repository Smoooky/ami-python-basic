# geo_point

Точка на поверхности Земли задаётся двумя углами. Широта отсчитывается от
экватора и лежит в пределах от −90° (Южный полюс) до 90° (Северный). Долгота
отсчитывается от Гринвичского меридиана и лежит от −180° до 180°. Значения вне
этих пределов не соответствуют ни одной точке планеты.

Расстояние между двумя точками считают не по прямой, а по дуге большого круга —
кратчайшему пути по поверхности шара. Формула гаверсинуса:

```
a = sin²(Δφ / 2) + cos(φ₁) · cos(φ₂) · sin²(Δλ / 2)
d = 2R · arcsin(√a)
```

где φ — широта в радианах, λ — долгота в радианах, Δφ и Δλ — их разности,
R — радиус Земли, 6371 км.

Реализовать класс `GeoPoint` с полями `latitude: float` и `longitude: float`,
объявленными в этом порядке.

## Что реализовать

* объект неизменяем: присваивание в поле после создания завершается ошибкой;
* объект хешируем: точку можно положить в множество и использовать ключом
  словаря;
* точки упорядочены: сравнение идёт сначала по широте, при равенстве — по
  долготе;
* значения вне допустимых пределов недопустимы: при создании такой точки
  возбуждается `ValueError`. Границы диапазонов входят в допустимые значения;
* `distance_to(self, other: "GeoPoint") -> float` — расстояние в километрах по
  формуле выше.

## Примеры

```python
moscow = GeoPoint(55.7558, 37.6173)
spb = GeoPoint(59.9311, 30.3609)

moscow.latitude  # 55.7558
round(moscow.distance_to(spb))  # 632
moscow.distance_to(moscow)  # 0.0
GeoPoint(0, 0).distance_to(GeoPoint(0, 180))  # половина экватора, ≈ 20015

sorted([GeoPoint(10, 20), GeoPoint(-5, 0), GeoPoint(10, 5)])
# [GeoPoint(-5, 0), GeoPoint(10, 5), GeoPoint(10, 20)]

len({GeoPoint(0, 0), GeoPoint(0, 0)})  # 1

moscow.latitude = 0  # ошибка: объект неизменяем
GeoPoint(91, 0)  # ValueError
GeoPoint(0, -181)  # ValueError
GeoPoint(90, 180)  # допустимо: границы входят в диапазон
```
