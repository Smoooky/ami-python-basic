# Семинар 6. Классы вблизи

Семинар к лекции 6: кто вызывает `__str__`, а кто `__repr__`, почему свой
`__eq__` лишает объект хеша, как `__slots__` перестают работать у наследника,
почему элемент `Enum` не равен своему значению и почему датакласс отказывается
создаваться с изменяемым значением по умолчанию.

Теория — в `Seminar6.ipynb`.

## Задачи

Лежат в `problems`. В CI они **не проверяются** и на баллы не влияют: решение
показывается преподавателю на семинаре вместе с зелёным прогоном тестов.

```
cd 0.06.Descriptors/seminar/problems
python3 -m pytest
```

Порядок — от простого к сложному:

1. `printing.py` — два способа показать объект;
2. `hashable.py` — объект, который годится в множество и в ключи;
3. `statuses.py` — перечисление на границе с внешними данными;
4. `records.py` — датакласс вместо ручной обвязки.

Разрешено всё из лекций 1–6 и всё, что разобрано в ноутбуках семинаров.
Исключения и контекстные менеджеры — тема лекции 7, здесь они не нужны:
там, где данные могут быть неверными, функции возвращают `None`.

Успеть все четыре задачи не обязательно: непройденное разбирается в начале
следующего семинара.
