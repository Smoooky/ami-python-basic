# parse_config

Файл с настройками программа читает один раз, при запуске. Если в нём восемь
ошибок, а загрузчик падает на первой, чинить их придётся по одной: правка,
перезапуск, новая ошибка, снова правка. Восемь перезапусков вместо одного.
Поэтому уважающий себя загрузчик проходит файл до конца, копит все замечания и
показывает их разом.

Копить получится только тогда, когда ошибка — это объект, а не напечатанная
строка. Объект помнит номер строки, имя ключа и вид проблемы; по нему можно
отсортировать, отфильтровать, посчитать. А раз видов ошибок несколько — значит,
иерархия классов: вызывающий код должен уметь поймать `except LineError`
целиком, а при желании только `except DuplicateKeyError`.

## Формат конфига

Одна пара `ключ = значение` на строку.

```
# комментарий
host = localhost
port = 8080
debug = false
```

* пустые строки и строки, начинающиеся с `#` (после отбрасывания пробелов по
  краям), пропускаются;
* строка делится по **первому** знаку `=`; всё, что после него, — значение,
  даже если там ещё есть `=`;
* ключ и значение обрезаются по краям от пробелов; `#` внутри значения ничего
  не начинает, это обычный символ;
* допустимый ключ непуст, состоит из строчных латинских букв, цифр и `_` и не
  начинается с цифры.

Значение приводится к типу: `true` — это `True`, `false` — `False`, то, на чём
не падает `int(value)`, — целое число, всё остальное — строка как есть. Только
в нижнем регистре: `True` — это строка `"True"`. Это не придирка — конфиги
читают люди, а «почти как булево» глазами не видно.

## Что реализовать

| Класс | Родитель | Дополнительные атрибуты | `str(error)` |
|---|---|---|---|
| `ConfigError` | `Exception` | `errors: list[LineError]` | `ошибок в конфиге: <N>` |
| `LineError` | `Exception` | `line: int` | `строка <line>: <причина>` |
| `MissingEqualsError` | `LineError` | — | причина: `нет знака =` |
| `BadKeyError` | `LineError` | `key: str` | причина: `недопустимый ключ '<key>'` |
| `BadValueError` | `LineError` | `key: str` | причина: `пустое значение для ключа '<key>'` |
| `DuplicateKeyError` | `LineError` | `key: str`, `first_line: int` | причина: `ключ '<key>' уже задан в строке <first_line>` |

Имя ключа в тексте — в кавычках, как его печатает `repr`.

* `parse_config(lines: list[str], strict: bool = True) -> dict[str, ConfigValue]` —
  разбирает все строки. При `strict=True` и хотя бы одной ошибке поднимает
  `ConfigError`, у которого `errors` — все найденные ошибки в порядке строк, а
  `__cause__` — первая из них. При `strict=False` исключения нет: испорченные
  строки просто не попадают в результат;
* `check_config(lines: list[str]) -> list[LineError]` — то же прохождение, но
  без исключений и без результата: режим «проверить конфиг, ничего не запуская».

Строки нумеруются с единицы, считаются все, включая пустые и комментарии. На
одну строку приходится не больше одной ошибки: проверки идут в порядке «нет
`=`» → «недопустимый ключ» → «ключ уже был задан» → «пустое значение», и первая
же сработавшая завершает разбор строки. «Уже был задан» — это раньше **успешно**
разобранная строка: ошибочная строка ключ не занимает, поэтому два `port` с
пустым значением дадут два `BadValueError`, а не дубликат. При дубликате в
результате остаётся значение из первой строки.

## Примеры

```python
config = parse_config(
    [
        "# сеть",
        "host = localhost",
        "port = 8080",
        "debug = false",
        "",
        "motd = добро пожаловать",
    ]
)
config
# {"host": "localhost", "port": 8080, "debug": False, "motd": "добро пожаловать"}

parse_config(["formula = a=b+c"])  # {"formula": "a=b+c"}
parse_config(["mode = True"])  # {"mode": "True"} — строка, не булево

broken = [
    "host = localhost",
    "просто текст",
    "Port = 80",
    "host = 127.0.0.1",
    "timeout =",
]

check_config(broken)
# [MissingEqualsError, BadKeyError, DuplicateKeyError, BadValueError]

[error.line for error in check_config(broken)]  # [2, 3, 4, 5]
str(check_config(broken)[2])
# "строка 4: ключ 'host' уже задан в строке 1"

parse_config(broken, strict=False)  # {"host": "localhost"}

try:
    parse_config(broken)
except ConfigError as error:
    str(error)  # "ошибок в конфиге: 4"
    len(error.errors)  # 4
    error.__cause__ is error.errors[0]  # True
    isinstance(error.errors[0], LineError)  # True
```
