# capture

В любом проекте, который прожил больше года, найдётся функция, печатающая отчёт
вместо того, чтобы его вернуть. Написали её быстро и для человека, а теперь
отчёт нужен программе: положить в лог, сверить в тесте. Переписывать нельзя —
на функцию завязано полдесятка мест.

Выход есть, потому что `print` не общается с терминалом напрямую: он пишет в
объект из `sys.stdout`, а это обычная переменная модуля. Её можно подменить на
`io.StringIO` — файл, которого нет на диске, — и весь вывод осядет в памяти.

Задачей про контекстные менеджеры это делает слово «потом»: подменённый
глобальный объект надо вернуть на место при любом исходе. Если функция внутри
блока упадёт, а `sys.stdout` останется подменённым, программа не остановится,
но онемеет — весь дальнейший вывод, включая сообщения об ошибках, будет уходить
в буфер, о котором уже никто не помнит. `__exit__` вызывается всегда, и это
единственная гарантия, которая тут нужна.

## Что реализовать

Класс `Captured`.

* `__enter__` — подменяет `sys.stdout` и возвращает сам объект, чтобы его можно
  было получить через `as`;
* `__exit__` — возвращает прежний `sys.stdout` на место и складывает
  накопленное в атрибуты. Исключение из тела блока не гасит;
* `text: str` — весь напечатанный текст целиком, ровно как его получил бы
  терминал: с переводами строк, которые добавил `print`;
* `lines: list[str]` — то же самое, разбитое на строки, без символов перевода
  строки. Пустой вывод даёт пустой список, а не список из одной пустой строки.

Результат доступен после выхода из блока, повторный вход начинает сбор заново.
Прежним `sys.stdout` считается тот, что стоял на момент входа, а не тот, что был
при запуске программы: только так вложенные блоки вернут всё как было.

## Примеры

```python
def print_report(rows: list[tuple[str, int]]) -> None:
    print("Отчёт")
    for name, count in rows:
        print(f"{name}: {count}")


with Captured() as out:
    print_report([("книги", 3), ("ручки", 12)])

out.text  # "Отчёт\nкниги: 3\nручки: 12\n"
out.lines  # ["Отчёт", "книги: 3", "ручки: 12"]

with Captured() as out:
    pass

out.lines  # []
```

```python
before = sys.stdout
try:
    with Captured() as out:
        print("успело напечататься")
        raise ValueError("а тут всё сломалось")
except ValueError:
    pass

sys.stdout is before  # True — вывод программе вернули
out.lines  # ["успело напечататься"]
```

```python
with Captured() as outer:
    print("наружное")
    with Captured() as inner:
        print("внутреннее")
    print("снова наружное")

inner.lines  # ["внутреннее"]
outer.lines  # ["наружное", "снова наружное"]
```
