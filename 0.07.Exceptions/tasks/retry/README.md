# retry

Половина ошибок при работе с сетью и файлами — временные. Wi-Fi моргнул, файл на
секунду занял другой процесс, флешку выдернули и вставили обратно. Такие
операции повторяют: вторая попытка через секунду обычно проходит. Вторая
половина ошибок — постоянные: `ValueError` на кривых данных не исправится ни со
второго раза, ни с десятого, а повтор только сожжёт время.

Поэтому у любого разумного механизма повторов есть список того, **что именно**
считается временным. Всё, чего в списке нет, должно вылететь наружу немедленно и
без обёрток: вызывающий код должен увидеть исходную ошибку, а не потерять её
внутри библиотеки. А когда попытки кончились, поднимается собственное
исключение, и исходная ошибка привязывается к нему причиной через
`raise ... from ...` — так в трейсбеке видно, из-за чего всё началось.

## Что реализовать

`RetryError` — исключение «попытки исчерпаны», наследник `Exception`.

* `__init__(self, attempts: int, last_error: BaseException)`;
* атрибуты `attempts` (сколько попыток сделано) и `last_error` (исключение
  последней попытки);
* `str(error)` равно `"попытки исчерпаны: <attempts>"`.

`retry(action, attempts=3, retry_on=(Exception,))` — где `action` это
`Callable[[], Any]`, а `retry_on` — кортеж классов исключений, которые считаются
временными.

* `attempts` меньше единицы — ошибка вызывающего: `ValueError`, причём `action`
  не вызывается ни разу;
* успешный вызов сразу возвращает результат, оставшиеся попытки не тратятся;
* исключение из `retry_on` (вместе с наследниками) — попытка повторяется;
* исключение **не** из `retry_on` улетает наружу как есть: ни повторов, ни
  `RetryError`. Пустой `retry_on` означает, что временных ошибок нет вовсе;
* когда попытки закончились, поднимается `RetryError`, у которого `__cause__` —
  исключение последней попытки. При `attempts=3` и всегда падающей операции
  `action` вызывается ровно три раза, не четыре.

Обратите внимание, что `retry_on` — обычная переменная, а не литерал: в блоке
`except` можно указать не только имя класса, но и выражение, дающее кортеж
классов.

## Примеры

```python
attempts_made = 0


def flaky() -> str:
    global attempts_made
    attempts_made += 1
    if attempts_made < 3:
        raise ConnectionError("соединение сброшено")
    return "ok"


retry(flaky, attempts=5)  # "ok", attempts_made == 3


def broken() -> None:
    raise ValueError("данные не разобрать")


retry(broken, attempts=2, retry_on=(ConnectionError,))
# ValueError — вылетает сразу, повторов не было

try:
    retry(broken, attempts=2)
except RetryError as error:
    str(error)  # "попытки исчерпаны: 2"
    error.attempts  # 2
    type(error.last_error)  # ValueError
    error.__cause__ is error.last_error  # True

retry(broken, attempts=0)  # ValueError: число попыток должно быть положительным
```
