# slice_parts

Реализовать функцию `slice_parts(text: str) -> tuple[str, str, str]`,
возвращающую три среза исходной строки:

1. строку, записанную задом наперёд;
2. каждый второй символ, начиная с первого (индексы 0, 2, 4, ...);
3. последние три символа.

## Сигнатура

```python
def slice_parts(text: str) -> tuple[str, str, str]: ...
```

## Примеры

```python
slice_parts("abcdef")  # ("fedcba", "ace", "def")
slice_parts("ab")  # ("ba", "a", "ab")
slice_parts("")  # ("", "", "")
```

Если в строке меньше трёх символов, третьим элементом возвращается вся строка —
именно так ведёт себя срез, отдельной обработки это не требует.
