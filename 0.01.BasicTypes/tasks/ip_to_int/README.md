# ip_to_int

IPv4-адрес записывается четырьмя числами от 0 до 255, разделёнными точками:
`192.168.1.1`. Каждое такое число помещается ровно в один байт — восемь бит.
Четыре байта подряд дают 32 бита, и весь адрес — это одно 32-битное целое
число. Точки нужны только человеку, для машины адрес неразделим.

## Старшие и младшие биты

Запишем число в двоичном виде и сравним с десятичной записью. В числе `538`
цифра `5` весит больше цифры `8`, потому что стоит левее: она обозначает сотни,
а `8` — единицы. С битами то же самое: чем левее бит, тем больше его вес.

Левые биты называют **старшими** (они дают наибольший вклад в значение),
правые — **младшими**.

В 32-битном числе биты нумеруются с 31-го слева до 0-го справа. Байты адреса
занимают их так:

```
     байт 1        байт 2        байт 3        байт 4
   ┌──────────┬──────────┬──────────┬──────────┐
   │ 31 .. 24 │ 23 .. 16 │ 15 ..  8 │  7 ..  0 │
   └──────────┴──────────┴──────────┴──────────┘
      старшие                          младшие
```

Первое число адреса попадает в старшие восемь бит, последнее — в младшие.
Поэтому изменение первого числа на единицу меняет значение адреса на
16 777 216, а изменение последнего — всего на единицу.

## Как это выглядит на примере

Возьмём `192.168.1.1` и запишем каждый байт двоично:

| Часть адреса | Двоичная запись | Позиции битов |
|---|---|---|
| `192` | `11000000` | 31 … 24 |
| `168` | `10101000` | 23 … 16 |
| `1` | `00000001` | 15 … 8 |
| `1` | `00000001` | 7 … 0 |

Все четыре записи, поставленные подряд, и есть искомое число:

```
11000000 10101000 00000001 00000001  =  3232235777
```

## Задача

Реализовать функцию `ip_to_int(address: str) -> int`, переводящую запись адреса
в это число.

## Сигнатура

```python
def ip_to_int(address: str) -> int: ...
```

## Примеры

```python
ip_to_int("0.0.0.0")  # 0
ip_to_int("0.0.0.1")  # 1
ip_to_int("0.0.1.0")  # 256
ip_to_int("192.168.1.1")  # 3232235777
ip_to_int("255.255.255.255")  # 4294967295
```

Адрес корректен, проверять его не нужно. Собрать число нужно битовыми
операциями, без возведения в степень и умножения.
