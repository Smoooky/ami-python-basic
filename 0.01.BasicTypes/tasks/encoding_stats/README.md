# encoding_stats

Реализовать функцию `encoding_stats(text: str) -> tuple[int, int, int, bool]`,
возвращающую четыре значения:

1. длину строки в символах;
2. длину её представления в кодировке UTF-8 в байтах;
3. длину её представления в кодировке UTF-16LE в байтах;
4. состоит ли строка целиком из символов ASCII.

Четвёртое значение вычислить сравнением двух первых, а не перебором символов.

## Сигнатура

```python
def encoding_stats(text: str) -> tuple[int, int, int, bool]: ...
```

## Примеры

```python
encoding_stats("abc")  # (3, 3, 6, True)
encoding_stats("café")  # (4, 5, 8, False)
encoding_stats("привет")  # (6, 12, 12, False)
encoding_stats("")  # (0, 0, 0, True)
```

Название кодировки для второго пункта — `"utf-8"`, для третьего — `"utf-16-le"`.
Вариант `"utf-16"` не подойдёт: он добавляет в начало двухбайтовую метку
порядка байт.

В UTF-8 символ занимает от одного до четырёх байт, в UTF-16LE — два или четыре.
Поэтому равенство числа символов и числа байт UTF-8 равносильно тому, что все
символы принадлежат ASCII.
