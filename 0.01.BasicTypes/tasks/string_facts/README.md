# string_facts

Реализовать функцию `string_facts(text: str) -> tuple[int, int, str]`,
которая возвращает три характеристики строки:

1. длину строки;
2. количество пробелов в ней;
3. эту же строку, приведённую к верхнему регистру.

## Сигнатура

```python
def string_facts(text: str) -> tuple[int, int, str]: ...
```

## Примеры

```python
string_facts("hello")  # (5, 0, "HELLO")
string_facts("a b c")  # (5, 2, "A B C")
string_facts("")  # (0, 0, "")
string_facts("привет мир")  # (10, 1, "ПРИВЕТ МИР")
```

Считать нужно только обычный пробел, табуляции и переводы строк пробелами не
считаются.
