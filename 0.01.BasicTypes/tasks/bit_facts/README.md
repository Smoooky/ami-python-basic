# bit_facts

Реализовать функцию `bit_facts(n: int, k: int) -> tuple[bool, int, int]`,
возвращающую три значения:

1. чётно ли число `n` — определить это **битовой операцией**, а не через `%`;
2. результат сдвига `n` влево на `k` бит;
3. количество единиц в двоичной записи `n`.

## Сигнатура

```python
def bit_facts(n: int, k: int) -> tuple[bool, int, int]: ...
```

## Примеры

```python
bit_facts(10, 1)  # (True, 20, 2)    10 = 0b1010
bit_facts(7, 3)  # (False, 56, 3)   7 = 0b111
bit_facts(0, 5)  # (True, 0, 0)
```

Оба аргумента неотрицательны.
