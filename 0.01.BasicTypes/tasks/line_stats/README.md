# line_stats

В одной строке через пробелы записаны целые числа. Реализовать функцию
`line_stats(line: str) -> tuple[int, int, int, int, float]`, возвращающую пять
значений в таком порядке:

1. количество чисел;
2. их сумму;
3. наибольшее;
4. наименьшее;
5. среднее арифметическое, округлённое до двух знаков после точки.

## Сигнатура

```python
def line_stats(line: str) -> tuple[int, int, int, int, float]: ...
```

## Примеры

```python
line_stats("1 2 3")  # (3, 6, 3, 1, 2.0)
line_stats("42")  # (1, 42, 42, 42, 42.0)
line_stats("-5 -1 -10")  # (3, -16, -1, -10, -5.33)
line_stats("  7   8  ")  # (2, 15, 8, 7, 7.5)
```

Гарантируется, что в строке есть хотя бы одно число. Лишние пробелы в начале, в
конце и между числами возможны.
