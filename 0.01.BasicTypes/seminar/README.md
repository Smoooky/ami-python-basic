# Семинар 1. Типы данных вблизи

Семинар к лекции 1: почему целые числа не переполняются, почему `-7 // 2` равно
`-4`, почему `0.1 + 0.2` не равно `0.3` и почему длина строки — не количество
букв. Форматирование строк сюда не входит — это тема второй лекции.

Теория — в `Seminar1.ipynb`. Перед ней два практических раздела: как сдаются
домашние задания и как устроено окружение проекта.

## Задачи

Лежат в `problems`. В CI они **не проверяются** и на баллы не влияют: решение
показывается преподавателю на семинаре вместе с зелёным прогоном тестов.

```
cd 0.01.BasicTypes/seminar/problems
python3 -m pytest
```

Порядок — от простого к сложному:

1. `divide.py` — деление, остаток и арифметика над сравнениями;
2. `money.py` — деньги в копейках вместо `float`;
3. `slices.py` — срезы и их ловушки;
4. `text.py` — кодовые точки, байты и нормализация;
5. `bits.py` — битовые операции.

Все функции решаются одним-двумя выражениями. Условные конструкции и циклы не
нужны нигде — их ещё не проходили. Разрешено всё из лекции 1 и всё, что
разобрано в ноутбуке семинара.

Успеть на паре все пять задач не обязательно: непройденное разбирается в начале
следующего семинара.
