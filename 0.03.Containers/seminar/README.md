# Семинар 3. Множества и словари вблизи

Семинар к лекции 3: почему `1`, `1.0` и `True` — это один ключ, почему порядок
множества меняется от запуска к запуску, почему `nan` находится в множестве
только иногда, чем оператор `|` строже метода `union` и почему `get` не
отличает отсутствие ключа от значения `None`.

Теория — в `Seminar3.ipynb`.

## Задачи

Лежат в `problems`. В CI они **не проверяются** и на баллы не влияют: решение
показывается преподавателю на семинаре вместе с зелёным прогоном тестов.

```
cd 0.03.Containers/seminar/problems
python3 -m pytest
```

Порядок — от простого к сложному:

1. `keys.py` — когда два значения оказываются одним ключом;
2. `sets.py` — операции над множествами, заданными списками;
3. `lookup.py` — поиск в словаре, где `None` — обычное значение;
4. `grouping.py` — группировка и подсчёт обычным словарём;
5. `orders.py` — множество как память о просмотренном.

Разрешено всё из лекций 1–3 и всё, что разобрано в ноутбуках семинаров.
`Counter` и `defaultdict` — тема лекции 10, здесь они не нужны.

Успеть на паре все пять задач не обязательно: непройденное разбирается в начале
следующего семинара.
