# word_frequency

Подсчёт частоты слов — основа поиска, антиплагиата и любой статистики по
текстам. Сложность не в самом подсчёте, а в том, что считать одним словом:
`Слово`, `слово` и `слово,` — это три разные строки, но одно слово.

Реализовать функцию `word_frequency(text: str) -> dict[str, int]`,
возвращающую словарь «слово — сколько раз встретилось».

## Правила нормализации

* слова разделяются пробельными символами;
* регистр не учитывается — `Дом` и `дом` считаются одним словом;
* знаки препинания `.,!?;:()"'` по краям слова отбрасываются, внутри слова —
  остаются: `что-то` это одно слово, а `дом,` — то же слово, что `дом`;
* если после отбрасывания знаков от слова ничего не осталось, оно не считается.

## Сигнатура

```python
def word_frequency(text: str) -> dict[str, int]: ...
```

## Примеры

```python
word_frequency("дом дом")  # {"дом": 2}
word_frequency("Дом, дом!")  # {"дом": 2}
word_frequency("что-то и что-то")  # {"что-то": 2, "и": 1}
word_frequency("")  # {}
word_frequency("-- ...")  # {"--": 1}
```

В последнем примере `--` состоит из дефисов, которые в список отбрасываемых
знаков не входят, а `...` отбрасывается целиком.
