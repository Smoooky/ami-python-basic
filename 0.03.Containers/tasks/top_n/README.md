# top_n

Есть словарь «слово — сколько раз встретилось». Нужно выбрать `n` самых частых.

## Правила упорядочивания

* сначала по убыванию количества;
* при равном количестве — по алфавиту, по возрастанию;
* если `n` больше числа записей, возвращаются все;
* результат — список пар `(слово, количество)`.

## Сигнатура

```python
def top_n(counts: dict[str, int], n: int) -> list[tuple[str, int]]: ...
```

## Примеры

```python
top_n({"a": 3, "b": 1, "c": 2}, 2)  # [("a", 3), ("c", 2)]
top_n({"b": 2, "a": 2}, 2)  # [("a", 2), ("b", 2)]
top_n({"a": 1}, 5)  # [("a", 1)]
top_n({}, 3)  # []
top_n({"a": 1}, 0)  # []
```

Количества — целые, могут быть нулевыми и отрицательными.
