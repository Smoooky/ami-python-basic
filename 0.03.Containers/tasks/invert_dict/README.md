# invert_dict

Реализовать функцию `invert_dict(mapping: dict[str, int]) -> dict[int, str]`,
меняющую ключи и значения местами: значение исходного словаря становится
ключом, ключ — значением.

## Сигнатура

```python
def invert_dict(mapping: dict[str, int]) -> dict[int, str]: ...
```

## Примеры

```python
invert_dict({"a": 1, "b": 2})  # {1: "a", 2: "b"}
invert_dict({})  # {}
invert_dict({"x": 1, "y": 1})  # {1: "y"}
```

Обратите внимание на третий пример: значения исходного словаря не обязаны быть
уникальными, а ключи результата — обязаны. При совпадении побеждает пара,
встреченная позже.
