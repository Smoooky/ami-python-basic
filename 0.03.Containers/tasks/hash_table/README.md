# hash_table

Словарь и множество в Python устроены поверх хеш-таблицы. В лекции она осталась
чёрным ящиком: ключ хешируется, и по хешу находится место. Здесь предстоит
собрать её упрощённую версию своими руками и увидеть, откуда берутся свойства,
которыми мы пользовались.

## Устройство

Хранилище — массив фиксированной длины, его ячейки называют **корзинами**.
Место для ключа выбирается по остатку от деления его хеша на число корзин:
таким образом любой ключ, каким бы большим он ни был, отображается в номер
существующей корзины.

Разные ключи неизбежно попадают в одну корзину — это называется **коллизией**.
Способ, который мы реализуем, называется методом цепочек: в каждой корзине
лежит список всех попавших в неё пар, и при поиске перебирается только он, а не
всё хранилище. Отсюда и берётся скорость: при удачном распределении в корзине
оказывается один-два элемента вместо тысяч.

Для целых чисел хеш в Python совпадает с самим числом, поэтому номер корзины —
это просто остаток от деления ключа на их количество. Помните, что знак остатка
следует за делителем: для положительного числа корзин результат всегда
неотрицателен, даже если ключ отрицательный.

## Обновление по существующему ключу

Если ключ уже лежит в своей корзине, новая пара не добавляется — обновляется
значение у существующей. При этом пара **остаётся на своём месте** в корзине, не
переезжая в конец. Это то же поведение, что у словаря: повторная запись по
ключу меняет значение, но не меняет порядок ключей.

## Задача

Реализовать функцию
`hash_table(pairs: list[tuple[int, str]], size: int) -> list[list[tuple[int, str]]]`,
которая раскладывает пары «ключ — значение» по `size` корзинам и возвращает
список корзин: от нулевой до последней. Каждая корзина — список пар в порядке
их добавления.

## Сигнатура

```python
def hash_table(pairs: list[tuple[int, str]], size: int) -> list[list[tuple[int, str]]]: ...
```

## Примеры

```python
hash_table([(1, "a"), (2, "b")], 2)
# [[(2, "b")], [(1, "a")]]

hash_table([(1, "a"), (3, "b")], 2)
# [[], [(1, "a"), (3, "b")]]        коллизия: оба ключа нечётные

hash_table([(1, "a"), (1, "b")], 2)
# [[], [(1, "b")]]                  обновление, а не вторая пара

hash_table([], 3)
# [[], [], []]

hash_table([(-1, "a")], 4)
# [[], [], [], [(-1, "a")]]         -1 % 4 равно 3
```

Число корзин не меньше единицы. Настоящая хеш-таблица при заполнении
увеличивает число корзин и раскладывает всё заново — здесь этого делать не
нужно, размер фиксирован.
