# dedup_keeping_order

Убрать повторы из списка можно одной операцией — превратив его во множество. Но
множество не хранит порядок, и после такого преобразования исходная
последовательность теряется безвозвратно.

Когда порядок важен — например, это история запросов или список шагов —
нужен другой приём: идти по списку и запоминать, что уже встречалось. Проверка
«встречалось ли» должна быть быстрой, иначе на длинных данных решение станет
квадратичным: у списка проверка вхождения требует перебора, у множества —
вычисления хеша.

Реализовать функцию `dedup_keeping_order(items: list[str]) -> list[str]`,
возвращающую элементы без повторов в порядке первого появления.

## Сигнатура

```python
def dedup_keeping_order(items: list[str]) -> list[str]: ...
```

## Примеры

```python
dedup_keeping_order(["b", "a", "b", "c"])  # ["b", "a", "c"]
dedup_keeping_order(["a", "a", "a"])  # ["a"]
dedup_keeping_order([])  # []
```

Остаётся **первое** вхождение каждого элемента. Решение должно оставаться
быстрым на списках в сотни тысяч элементов.
