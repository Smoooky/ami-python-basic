# group_by_length

Группировка — одна из самых частых операций над данными: разложить элементы по
корзинам, у каждой корзины свой ключ. В Python корзины естественно хранить в
словаре, где значение — список.

Реализовать функцию `group_by_length(words: list[str]) -> dict[int, list[str]]`,
раскладывающую слова по их длине.

## Правила

* ключ — длина слова, значение — список слов такой длины;
* внутри списка сохраняется **исходный порядок** слов;
* повторяющиеся слова попадают в список столько раз, сколько встретились;
* пустых списков в результате быть не должно.

## Сигнатура

```python
def group_by_length(words: list[str]) -> dict[int, list[str]]: ...
```

## Примеры

```python
group_by_length(["кот", "дом", "море"])  # {3: ["кот", "дом"], 4: ["море"]}
group_by_length(["a", "b", "a"])  # {1: ["a", "b", "a"]}
group_by_length([])  # {}
group_by_length([""])  # {0: [""]}
```

Порядок ключей в словаре — порядок их появления: ключ создаётся, когда
встретилось первое слово соответствующей длины.
