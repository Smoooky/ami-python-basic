# unique_sorted

Реализовать функцию `unique_sorted(numbers: list[int]) -> list[int]`,
возвращающую уникальные значения списка, упорядоченные по возрастанию.

## Сигнатура

```python
def unique_sorted(numbers: list[int]) -> list[int]: ...
```

## Примеры

```python
unique_sorted([3, 1, 2, 3, 1])  # [1, 2, 3]
unique_sorted([5])  # [5]
unique_sorted([])  # []
```

Исходный список менять не нужно.
