# merge_prices

Есть базовый прайс-лист и список обновлений. Реализовать функцию
`merge_prices(base: dict[str, int], updates: dict[str, int]) -> dict[str, int]`,
возвращающую **новый** словарь: товары из обоих, а при совпадении названия цена
берётся из обновлений.

## Сигнатура

```python
def merge_prices(base: dict[str, int], updates: dict[str, int]) -> dict[str, int]: ...
```

## Примеры

```python
merge_prices({"хлеб": 50}, {"молоко": 80})  # {"хлеб": 50, "молоко": 80}
merge_prices({"хлеб": 50}, {"хлеб": 60})  # {"хлеб": 60}
merge_prices({}, {})  # {}
```

Исходные словари меняться не должны — это важно: вызывающий код продолжит
пользоваться базовым прайсом.
