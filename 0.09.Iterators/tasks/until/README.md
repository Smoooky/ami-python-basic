# until

Одна и та же форма встречается в программах постоянно: звать что-то раз за
разом, пока не придёт условленный ответ. Кидать кубик, пока не выпадет шестёрка.
Читать файл кусками, пока не вернётся пустая строка. Спрашивать у пользователя
команду, пока он не напишет «стоп».

Пишут это обычно так:

```python
result = []
while True:
    value = roll()
    if value == 6:
        break
    result.append(value)
```

Четыре строки служебного механизма на одну строку дела, и в каждой можно
ошибиться: перепутать порядок `break` и `append`, забыть про первый вызов.

У встроенной функции `iter` есть вторая форма, ровно про этот случай:
`iter(функция, sentinel)`. Она возвращает итератор, который на каждом шаге зовёт
функцию **без аргументов** и отдаёт результат, а когда результат окажется равен
`sentinel` — останавливается, как и положено итератору. Сам `sentinel` наружу не
выходит. Сравнение идёт через `==`, а не через `is`.

Функция должна быть без аргументов, а нужная почти всегда с аргументами —
поэтому в паре с этой формой ходит `functools.partial`: `partial(read, 3)` даёт
функцию, которая зовёт `read(3)`.

## Что реализовать

* `collect(source: Callable[[], Any], sentinel: Any) -> list[Any]` — вызывать
  `source`, пока не вернётся `sentinel`, и собрать всё, что было до него.
  Сам `sentinel` в список не попадает, а после него `source` больше не зовут;
* `read_chunks(read: Callable[[int], str], size: int) -> list[str]` — прочитать
  текст кусками по `size` символов. Функция `read(n)` возвращает не больше `n`
  символов, а когда читать больше нечего — пустую строку. Последний кусок может
  оказаться короче остальных. Размер меньше единицы — `ValueError`, и проверить
  его надо **до** первого чтения;
* `first_hit(source: Callable[[], Any], sentinel: Any, target: Any) -> int | None` —
  номер вызова (считая с единицы), в котором впервые встретилось значение
  `target`. Если до `sentinel` оно так и не встретилось — `None`. Дальше
  найденного `source` не зовут.

Все три пишутся через вторую форму `iter`; ни один `while True` не нужен.

## Примеры

```python
def roll_of(values):  # кубик с заранее известными бросками
    throws = iter(values)
    return lambda: next(throws)


collect(roll_of([3, 5, 2, 6, 4]), 6)  # [3, 5, 2] — шестёрка не в счёт
collect(roll_of([6, 1, 2]), 6)  # []
```

```python
import io

text = io.StringIO("абвгдеж")
read_chunks(text.read, 3)  # ["абв", "где", "ж"]

read_chunks(io.StringIO("").read, 3)  # []
read_chunks(io.StringIO("абв").read, 0)  # ValueError
```

```python
first_hit(roll_of([3, 5, 1, 6]), 6, 1)  # 3 — единица выпала третьей
first_hit(roll_of([3, 5, 6, 1]), 6, 1)  # None — до неё выпала шестёрка
first_hit(roll_of([6]), 6, 6)  # None — sentinel не считается

collect(roll_of([1, 2, 1.0, 3]), 1.0)  # [] — сравнение через ==, 1 == 1.0
```
