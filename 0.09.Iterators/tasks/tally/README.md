# tally

Генератор, который мы видели до сих пор, работал в одну сторону: отдавал
значения наружу и ничего не получал взамен. Но связь двусторонняя. Выражение
`yield` — это именно выражение, у него есть результат, и результат этот приходит
снаружи:

```python
name = yield counts
```

Строка означает: отдать наружу `counts`, замереть, а когда нас разбудят —
получить присланное значение в `name` и пойти дальше. Будят методом `send`:
`gen.send("аня")` возобновляет генератор, кладёт `"аня"` в `name` и возвращает
то, что генератор отдаст следующим `yield`.

Получается объект, который помнит своё состояние между вызовами и при этом
описан обычным линейным кодом, без класса и без полей. На таком удобно считать
голоса: подсчёт старосты — это ровно «принять очередное имя, вернуть текущий
расклад».

Первый `send` обязан быть `send(None)` или, что то же самое, `next(gen)`:
генератор ещё не дошёл ни до одного `yield`, и присылать значение некуда. Это
называется «раскрутить» генератор. Попытка сразу послать что-то другое — сразу
`TypeError`.

## Что реализовать

* `tally() -> Generator[dict[str, int], str | None, None]` — приёмник голосов.
  Первый `next` доводит его до первого `yield` и отдаёт пустой расклад.
  Каждый `send(имя)` добавляет голос и отдаёт текущий расклад — **новый**
  словарь, а не тот же самый объект, чтобы старый снимок не менялся задним
  числом. `send(None)` завершает приёмник, то есть возбуждает у вызывающего
  `StopIteration`. Имена идут в порядке первого голоса за них;
* `feed(votes: Iterable[str]) -> dict[str, int]` — прогнать все голоса через
  приёмник и вернуть итоговый расклад. Приёмник надо закрыть, чем бы дело ни
  кончилось;
* `leaders(votes: Iterable[str]) -> Generator[str | None, None, None]` — кто
  ведёт после каждого голоса. Если первое место делят несколько человек — `None`.
  Функция ленивая: очередной ответ считается только тогда, когда его попросят.

Обратите внимание: `next(gen)` — это то же самое, что `send(None)`. Значит,
после раскрутки обычный `next` приёмник не продвинет, а завершит.

## Примеры

```python
counter = tally()
next(counter)  # {} — раскрутили
counter.send("аня")  # {"аня": 1}
counter.send("боря")  # {"аня": 1, "боря": 1}
counter.send("аня")  # {"аня": 2, "боря": 1}
counter.send(None)  # StopIteration

counter = tally()
empty = next(counter)
counter.send("аня")
empty  # {} — снимок не поменялся
```

```python
feed(["аня", "боря", "аня"])  # {"аня": 2, "боря": 1}
feed([])  # {}

list(leaders(["аня", "боря", "аня"]))  # ["аня", None, "аня"]
list(leaders(["а", "а", "б", "б"]))  # ["а", "а", "а", None]
list(leaders([]))  # []
```
