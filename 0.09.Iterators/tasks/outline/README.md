# outline

План конспекта — это вложенные списки: раздел, внутри него подразделы, внутри
них ещё подразделы. Глубина заранее неизвестна и у каждого своя.

```python
plan = ["Введение", ["Что такое итератор", ["Протокол", "Примеры"]], "Заключение"]
```

Разложить такое в плоский список — задача для рекурсии: пункт либо строка, и
тогда его отдают, либо список, и тогда с ним поступают так же, как со всем
планом. Написать это через `yield` можно, но получится некрасиво:

```python
for item in inner:
    yield item
```

Такой цикл — целиком служебный, он ничего не делает, только перекладывает. Для
него есть отдельная конструкция: `yield from inner` отдаёт наружу все элементы
`inner` по очереди и означает ровно то же самое. `inner` при этом может быть чем
угодно перебираемым — списком, генератором, строкой.

## Что реализовать

Пункт плана — это `Item`, то есть `str | list["Item"]`: либо строка, либо список
таких же пунктов.

* `flat(outline: Iterable[Item]) -> Iterator[str]` — все пункты подряд, слева
  направо, без вложенности;
* `numbered(outline: Iterable[Item], level: int = 0) -> Iterator[tuple[int, str]]` —
  то же самое, но парами «уровень, пункт». Верхний уровень — нулевой; аргумент
  `level` говорит, с какого номера начинать, и используется при спуске внутрь;
* `depth(outline: Iterable[Item]) -> int` — на сколько уровней вложен план.
  У пустого плана глубина 0, у плоского — 1;
* `chain(*sources: Iterable[Any]) -> Iterator[Any]` — выдать подряд элементы
  всех переданных источников. Без источников — пусто.

`flat`, `numbered` и `chain` — генераторы, и `yield from` в них уместен во всех
трёх. Ленивость важна: `chain` не должен трогать следующий источник, пока не
исчерпан предыдущий, поэтому бесконечный источник в конце цепочки ничему не
мешает.

## Примеры

```python
plan = ["Введение", ["Что такое итератор", ["Протокол", "Примеры"]], "Заключение"]

list(flat(plan))
# ["Введение", "Что такое итератор", "Протокол", "Примеры", "Заключение"]

list(numbered(plan))
# [(0, "Введение"), (1, "Что такое итератор"), (2, "Протокол"),
#  (2, "Примеры"), (0, "Заключение")]

depth(plan)  # 3
depth(["а", "б"])  # 1
depth([])  # 0
depth([[[["глубоко"]]]])  # 4

list(flat(["а", [], ["б", []]]))  # ["а", "б"] — пустые ветки просто пропускаются
list(numbered(["а"], 5))  # [(5, "а")]
```

```python
list(chain([1, 2], [3], []))  # [1, 2, 3]
list(chain("аб", [1]))  # ["а", "б", 1]
list(chain())  # []

walk = chain([1, 2], naturals())  # naturals() из задачи pipeline, бесконечен
[next(walk) for _ in range(4)]  # [1, 2, 0, 1]
```
