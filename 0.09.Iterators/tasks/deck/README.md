# deck

По колоде карт можно пройти циклом `for`. По раздаче — тоже. Разница между ними
видна только со второго раза: колода останется прежней, а раздача кончится и
больше ничего не выдаст.

За `for` стоят два разных объекта и два разных протокола. **Итерируемый объект**
(iterable) умеет по требованию выдать того, кто будет его перебирать: метод
`__iter__` возвращает **новый** итератор. Сам объект при этом ничего не помнит и
не тратится. **Итератор** (iterator) — это уже сам обход, у него есть состояние
«где мы сейчас»: метод `__next__` отдаёт следующий элемент, а когда элементы
кончились, возбуждает `StopIteration`. Метод `__iter__` у итератора возвращает
`self` — иначе его нельзя было бы подставить в `for`.

Цикл `for x in источник` делает ровно это: один раз зовёт `iter(источник)`, а
потом дёргает `next` у полученного итератора, пока не поймает `StopIteration`.
В задаче `playlist` перебор шёл в обход этой схемы, по старому пути через
`__getitem__`. Здесь — по основному.

## Что реализовать

`Dealer` — итератор, выдающий карты по одной.

* `__init__(self, cards: list[str])` — список копируется;
* `__next__` — следующая карта; когда карты кончились — `StopIteration`, и на
  каждый следующий вызов тоже: исчерпанный итератор не оживает;
* `__iter__` — возвращает `self`;
* атрибут `dealt: int` — сколько карт уже выдано;
* `__repr__` — `Dealer(выдано 1 из 3)`.

`Deck` — итерируемая колода.

* `__init__(self, cards: list[str])` — список копируется;
* `__iter__` — **новый** `Dealer` на каждый вызов, поэтому по колоде можно
  пройти сколько угодно раз;
* `__len__` и `__repr__` — `Deck(['туз'])`. Метода `__next__` у колоды быть не
  должно.

Две проверки, ровно по определениям выше:

* `is_iterable(value: Any) -> bool` — можно ли получить итератор: позвать `iter`
  и поймать `TypeError`;
* `is_iterator(value: Any) -> bool` — итератор ли это, то есть верно ли, что
  `iter(value) is value`.

## Примеры

```python
deck = Deck(["туз", "король", "дама"])

list(deck)  # ["туз", "король", "дама"]
list(deck)  # то же самое: колода не потратилась
len(deck)  # 3
"дама" in deck  # True — in тоже перебирает, но берёт новый Dealer

dealer = iter(deck)
next(dealer)  # "туз"
dealer.dealt  # 1
list(dealer)  # ["король", "дама"] — продолжили с того же места
list(dealer)  # [] — раздача кончилась
next(dealer)  # StopIteration

iter(dealer) is dealer  # True
iter(deck) is iter(deck)  # False — каждый раз новый раздающий
```

```python
is_iterable(deck)  # True
is_iterator(deck)  # False — колода не помнит, где мы остановились
is_iterator(iter(deck))  # True

is_iterable("строка")  # True
is_iterable(42)  # False
is_iterator([1, 2])  # False
is_iterator(iter([1, 2]))  # True
is_iterator(number for number in [1])  # True — генератор всегда итератор
```
