# hello_world

Первая задача курса. Реализовать функцию `greet(name: str) -> str`,
возвращающую строку `"Hello, <name>!"`.

## Сигнатура

```python
def greet(name: str) -> str: ...
```

## Примеры

```python
greet("world")  # "Hello, world!"
greet("АМИ")  # "Hello, АМИ!"
greet("")  # "Hello, !"
```
