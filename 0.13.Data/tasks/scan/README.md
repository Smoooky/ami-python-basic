# scan

Обход дерева каталогов, который не собирает список. Файлов может оказаться
миллион, а нужны из них первые три — значит, остальные не должны быть даже
прочитаны.

## Что реализовать

* `walk(root)` — пути ко всем файлам дерева. Каталоги в ответ не попадают, но
  просматриваются. Порядок: в каждом каталоге записи по возрастанию имени, и в
  подкаталог обход заходит на его месте в этом порядке. Возвращается генератор,
  а не список: до первого запроса значения не должно происходить ничего, в том
  числе обращений к диску;
* `take(source, count)` — первые `count` элементов любого источника, списком.
  Элементов меньше — вернутся все, сколько есть. У источника не должно быть
  запрошено ни одного лишнего элемента. Отрицательный `count` — `ValueError`,
  и проверка происходит до первого обращения к источнику;
* `first(root, suffix)` — первый в порядке обхода файл с таким расширением, или
  `None`. Расширение задаётся как в `Path.suffix`, то есть с точкой; пустая
  строка означает файлы без расширения;
* `by_suffix(root)` — сколько файлов каждого расширения. Ключи по алфавиту;
* `total_size(root)` — суммарный размер файлов дерева в байтах;
* `largest(root)` — самый большой файл. При равном размере побеждает тот, кто
  раньше в порядке обхода; файлов нет — `None`.

Несуществующий каталог — `FileNotFoundError` из `pathlib`, ловить и подменять
его не нужно.

## Как посмотреть глазами

`demo.py` строит небольшое дерево во временном каталоге и прогоняет по нему все
функции:

```bash
python demo.py
```

```
что нашёл обход, в том порядке, в каком отдаёт:
  readme                              36 б
  картинка.png                       120 б
  конспект.txt                        33 б
  лекции/вторая.txt                    4 б
  лекции/первая.txt                    2 б
  лекции/черновики/набросок.md        18 б
  пусто/.keep                          0 б
```

Каталог `лекции` стоит в списке между `конспект.txt` и `пусто`, и обход заходит
внутрь него именно там. На оценку `demo.py` не влияет.

## Примеры

```python
list(walk(root))
# [Path('.../readme'), Path('.../картинка.png'), Path('.../лекции/первая.txt')]

take(walk(root), 2)  # первые два файла
take(range(100), 3)  # [0, 1, 2]
take([1, 2], 5)  # [1, 2]
take([1, 2], -1)  # ValueError
```

```python
first(root, ".png")  # Path('.../картинка.png')
first(root, ".zip")  # None
first(root, "")  # первый файл без расширения

by_suffix(root)  # {'': 2, '.md': 1, '.png': 1, '.txt': 3}
total_size(root)  # 213
largest(root)  # Path('.../картинка.png')
```
