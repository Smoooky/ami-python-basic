# dumps

Написать `json.dumps` самому. Модулем `json` пользоваться нельзя.

## Что реализовать

* `dump_string(text)` — строка в JSON-записи: в кавычках и с экранированием.
  Готовый словарь коротких замен — `ESCAPES` в шапке модуля, остальные символы
  до пробела пишутся как `\u00XX`. Кириллица остаётся собой;
* `dumps(value)` — значение целиком, в одну строку. Разделители такие же, как у
  модуля: `", "` между элементами и `": "` между ключом и значением;
* `dumps_sorted(value)` — то же, но ключи каждого объекта по алфавиту, на всех
  уровнях вложенности. Списки не сортируются.

Для всего, что поддержано, результат обязан совпадать с `json.dumps(value,
ensure_ascii=False)` посимвольно — тесты сравнивают именно так.

## Что поддержано

`None`, `bool`, `int`, `float`, `str`, `list` и `dict` со строковыми ключами.
Вложенность любая.

`True` и `False` записываются как `true` и `false` — в том числе внутри списков
и словарей.

## Что считается ошибкой

Здесь мы строже модуля: в первых трёх случаях `json.dumps` молча меняет данные,
а мы отказываемся.

| случай | у нас | у `json.dumps` |
|---|---|---|
| нестроковый ключ, `{1: "a"}` | `TypeError` | даст `{"1": "a"}` |
| `tuple` | `TypeError` | даст массив |
| `nan`, `inf` | `ValueError` | напишет `NaN` и `Infinity` |
| `set`, `bytes`, свой объект | `TypeError` | `TypeError` |
| значение ссылается само на себя | `ValueError` | `ValueError` |

Последняя строка — только про настоящий цикл. Один и тот же объект, встреченный
в документе дважды, ошибкой не является и записывается два раза.

## Примеры

```python
dumps({"тема": "тёмная", "интервал": 10})  # '{"тема": "тёмная", "интервал": 10}'
dumps([1, True, None, 2.5])  # '[1, true, null, 2.5]'
dumps({"a": [1, {"b": None}]})  # '{"a": [1, {"b": null}]}'

dumps_sorted({"б": 1, "а": 2})  # '{"а": 2, "б": 1}'
dumps_sorted([3, 1, 2])  # '[3, 1, 2]' — списки не трогаем
```

```python
dump_string('он сказал "да"')  # '"он сказал \\"да\\""'
dump_string("две\nстроки")  # '"две\\nстроки"'
dump_string("\x00")  # '"\\u0000"'
```

```python
shared = [1, 2]
dumps([shared, shared])  # '[[1, 2], [1, 2]]'

loop = [1]
loop.append(loop)
dumps(loop)  # ValueError
```
