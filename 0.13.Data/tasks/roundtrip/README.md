# roundtrip

Значение записали в JSON и прочитали обратно. Не всякое вернётся тем же —
задача в том, чтобы заранее сказать, какое именно и что с ним случится.

Здесь модулем `json` пользоваться **можно**: задача не в том, чтобы повторить
его, а в том, чтобы разобраться, что он делает с данными.

## Что реализовать

* `as_key(key)` — строка, которой этот ключ станет в записанном объекте.
  Поддержаны `str`, `int`, `float`, `bool` и `None`; остальное — `TypeError`,
  а `nan` и `inf` — `ValueError`. Готовый словарь `NAMED` в шапке модуля
  задаёт запись для тех значений, у которых она не совпадает с `str()`;
* `key_conflicts(mapping)` — те строки, за которые борются два или более ключа
  исходного словаря, по алфавиту. Если конфликтов нет, список пустой;
* `restored(value)` — что вернётся после записи и чтения. Ошибки записи
  проходят наружу;
* `survives(value)` — вернулось ли значение, равное исходному. Здесь ошибки
  наружу не проходят: значение, которое нельзя записать, просто не переживает
  запись, и ответ `False`.

## Примеры

```python
as_key(1)  # '1'
as_key(True)  # 'true'
as_key(None)  # 'null'
as_key(1.5)  # '1.5'
as_key((1, 2))  # TypeError
```

```python
key_conflicts({"a": 1, "b": 2})  # []
key_conflicts({1: "a", "1": "b"})  # ['1']
key_conflicts({True: "a", "true": "b"})  # ['true']
```

```python
restored([1, 2])  # [1, 2]
restored((1, 2))  # [1, 2]
restored({1: "a"})  # {'1': 'a'}

survives("текст")  # True
survives((1, 2))  # False
survives({1, 2})  # False
```
