# Семинар 5. Функции и классы вблизи

Семинар к лекции 5: почему `total = total + 1` внутри функции падает с
`UnboundLocalError`, почему аннотация типа никого не останавливает, почему
список, объявленный в теле класса, оказывается общим для всех объектов, что
лежит в `obj.method`, если метод не вызвать, и как словарь функций заменяет
цепочку `if`. Правило LEGB, `nonlocal` и замыкания — тема лекции 11, их здесь
нет.

Теория — в `Seminar5.ipynb`. Одна ячейка в нём намеренно завершается ошибкой —
это часть разбора.

## Задачи

Лежат в `problems`. В CI они **не проверяются** и на баллы не влияют: решение
показывается преподавателю на семинаре вместе с зелёным прогоном тестов.

```
cd 0.05.Functions/seminar/problems
python3 -m pytest
```

Порядок — от простого к сложному:

1. `dispatch.py` — таблица функций вместо цепочки условий;
2. `about.py` — что можно узнать о функции, не вызывая её;
3. `notes.py` — класс, состояние которого принадлежит объекту;
4. `stack.py` — стопка значений, пустая без исключений.

Разрешено всё из лекций 1–5 и всё, что разобрано в ноутбуках семинаров.
Наследование, `property`, `dataclass` и `Enum` — тема лекции 6, здесь они не
нужны.

Успеть на паре все четыре задачи не обязательно: непройденное разбирается в
начале следующего семинара.
