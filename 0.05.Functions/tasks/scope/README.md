# scope

Имя, которому присвоили внутри функции, живёт только там. Снаружи его нет —
даже если снаружи есть имя с тем же написанием. Чтобы функция меняла имя из
модуля, а не заводила своё, нужно объявить это явно словом `global`.

Со списками получается тоньше. Аргумент функции — это ссылка на тот же объект,
который держит вызывающий. Поэтому вопрос «увидит ли вызывающий изменение»
решается не тем, что происходит внутри функции, а тем, **меняете вы объект или
переприсваиваете имя**:

```python
def in_place(values):
    values += [1]  # меняет объект — вызывающий увидит


def rebind(values):
    values = values + [1]  # заводит новый список и цепляет к локальному имени
    # вызывающий не увидит ничего
```

`+=` на списке — это `list.__iadd__`, то есть изменение на месте. `values = values
+ [1]` строит новый список и присваивает его локальному имени, а объект
вызывающего остаётся нетронутым. Выглядит почти одинаково, последствия
противоположные.

## Что реализовать

В модуле объявлено имя `total = 0`.

* `add(value)` — прибавить к `total` и вернуть новое значение. Меняться должно
  именно имя в модуле, а не локальная копия;
* `reset()` — вернуть `total` в ноль;
* `extend_in_place(values, extra)` — дописать `extra` в конец `values`, изменив
  список вызывающего. Ничего не возвращает;
* `rebind(values, extra)` — вернуть список из обоих, **не тронув** аргумент.
  Внутри имя `values` переприсваивается;
* `extend_copy(values, extra)` — то же самое, но сразу собирая новый список.
  Ни один из аргументов не меняется.

`rebind` и `extend_copy` возвращают одно и то же — разница в том, как они к
этому приходят. Обе не трогают вызывающего, и в этом весь смысл сравнения с
`extend_in_place`.

## Примеры

```python
import scope

reset()
add(3)  # 3
add(4)  # 7
scope.total  # 7 — функция поменяла имя в модуле
reset()
scope.total  # 0
```

```python
values = [1, 2]
extend_in_place(values, [3])
values  # [1, 2, 3] — список вызывающего изменился

values = [1, 2]
rebind(values, [3])  # [1, 2, 3]
values  # [1, 2] — а тут нет

values = [1, 2]
extend_copy(values, [3])  # [1, 2, 3]
values  # [1, 2]
```
