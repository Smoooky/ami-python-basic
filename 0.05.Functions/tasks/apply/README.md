# apply

Функция в питоне — обычный объект: её можно положить в переменную, передать
аргументом и вернуть из другой функции. Последнее и есть самое интересное:
функция, которая возвращает функцию, позволяет собрать нужное поведение из
готовых кусков вместо того, чтобы писать его заново.

Возвращаемая функция помнит то, что было в момент её создания, — переданные
шаги, зафиксированные аргументы, число повторов. Это называется замыканием, и
подробно о нём будет в лекции про декораторы; пока достаточно знать, что
внутренняя функция видит имена внешней и после того, как внешняя вернулась.

Важно, что **ничего не вызывается заранее**. `compose([...])` не запускает шаги,
а только собирает их; работа начинается, когда позовут результат.

## Что реализовать

* `compose(steps)` — собрать конвейер: вернуть функцию, которая прогоняет
  значение через все шаги **слева направо**. Результат каждого шага уходит
  следующему. Пустой список шагов даёт функцию, возвращающую значение как есть;
* `partial(func, *args, **kwargs)` — зафиксировать часть аргументов: вернуть
  функцию, которая при вызове добавит к ним остальные и позовёт `func`.
  Зафиксированные позиционные идут **перед** переданными при вызове;
  зафиксированные именованные можно переопределить при вызове;
* `repeat(func, times)` — вернуть функцию, применяющую `func` к значению `times`
  раз подряд. Ноль повторов возвращает значение нетронутым; отрицательное число
  ведёт себя так же, как ноль, — `range` от него пуст, и разбирать этот случай
  отдельно не нужно.

Результат каждой из трёх функций можно вызывать сколько угодно раз, и вызовы не
должны влиять друг на друга.

## Примеры

```python
def double(value):
    return value * 2


def increment(value):
    return value + 1


compose([double, increment])(3)  # 7 — сначала удвоили, потом прибавили
compose([increment, double])(3)  # 8 — порядок важен
compose([])(5)  # 5

repeat(double, 3)(1)  # 8
repeat(increment, 0)(7)  # 7
repeat(double, -1)(7)  # 7 — как и ноль повторов
```

```python
def power(base, exponent):
    return base**exponent


squares = partial(power, exponent=2)
squares(5)  # 25

of_two = partial(power, 2)
of_two(10)  # 1024


def greet(name, greeting="привет"):
    return f"{greeting}, {name}"


hello = partial(greet, greeting="здорово")
hello("Аня")  # "здорово, Аня"
hello("Аня", greeting="салют")  # "салют, Аня" — вызов перебивает
```

```python
pipeline = compose([increment, partial(power, exponent=2), double])
pipeline(2)  # 18: 2 -> 3 -> 9 -> 18
```
