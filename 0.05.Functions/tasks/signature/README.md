# signature

Объявляя функцию, вы решаете не только какие у неё параметры, но и **как их
разрешено передавать**. Для этого в списке параметров бывают два разделителя:

```python
def f(a, b, /, c, d, *, e, f): ...


#           ^          ^
#     всё до / — только по позиции
#                всё после * — только по имени
#           между ними — можно и так, и так
```

Зачем это нужно. Позиционные-только параметры не дают вызывающему завязаться на
имя: имя `x` потом можно переименовать, не ломая чужой код. Именованные-только,
наоборот, заставляют вызывающего написать имя — и вызов `settings("localhost",
8080, True, False)` превращается в читаемый.

У позиционного-только параметра есть и второе, менее очевидное следствие: его
имя **освобождается**. Раз по имени его всё равно не передать, это имя может
занять что-то другое — например, попасть в `**options`:

```python
def move(distance, /, **options):
    return (distance, options)


move(5, distance="fast")  # (5, {'distance': 'fast'})
```

Пятёрка ушла в `distance` по позиции, а строка — в `options` под тем же именем,
и они друг другу не мешают. Без разделителя `/` так собрать вызов было бы
нельзя вовсе.

Раскладывает аргументы по параметрам и распаковка: `func(*positional, **named)`
отправляет список по позициям, а словарь по именам.

## Что реализовать

Три функции с в точности такими сигнатурами:

* `linear(x, /, slope=1.0, intercept=0.0)` — считает `slope * x + intercept`.
  `x` передаётся только по позиции;
* `settings(*, host, port=80)` — возвращает строку `"host:port"`. Оба параметра
  передаются только по имени, у `host` умолчания нет;
* `mixed(a, b=0, /, *, c=0)` — сумма трёх чисел. `a` и `b` только по позиции,
  `c` только по имени;
* `move(distance, /, **options)` — возвращает пару из `distance` и словаря
  остальных именованных аргументов. Разделитель тут обязателен: без него
  `move(5, distance="fast")` собрать не получится.

И одна функция про вызов:

* `call_with(func, positional, named)` — вызвать `func`, разложив список по
  позициям, а словарь по именам, и вернуть результат.

## Примеры

```python
linear(1)  # 1.0
linear(1, 10)  # 10.0
linear(2, slope=10, intercept=3)  # 23.0

settings(host="localhost")  # "localhost:80"
settings(host="localhost", port=8080)  # "localhost:8080"

mixed(1)  # 1
mixed(1, 2)  # 3
mixed(1, 2, c=3)  # 6
```

```python
move(5)  # (5, {})
move(5, distance="fast")  # (5, {'distance': 'fast'})
move(5, speed=2, distance="fast")  # (5, {'speed': 2, 'distance': 'fast'})
```

```python
call_with(linear, [2], {"slope": 3})  # 6.0
call_with(settings, [], {"host": "a", "port": 1})  # "a:1"
call_with(mixed, [1, 2], {"c": 3})  # 6
call_with(move, [5], {"distance": "fast"})  # (5, {'distance': 'fast'})
```
