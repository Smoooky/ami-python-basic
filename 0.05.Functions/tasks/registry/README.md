# registry

У класса и у его экземпляров разные пространства имён. Поле, объявленное в теле
класса, принадлежит самому классу и общее для всех экземпляров. Поле,
присвоенное через `self`, принадлежит конкретному экземпляру.

Реализовать класс `Registry`, ведущий учёт созданных экземпляров.

## Что реализовать

* поле класса `created` — сколько экземпляров создано за всё время. Общее для
  всех, начинается с нуля и увеличивается в конструкторе. Значение читается и
  через класс, и через любой экземпляр;
* `__init__(self, name: str)` — сохраняет `name` в поле экземпляра;
* поле экземпляра `items` — список, свой у каждого экземпляра, изначально
  пустой. Добавление элемента в один экземпляр не должно быть видно в других;
* `add(self, item: str) -> None` — добавляет элемент в `items` этого
  экземпляра;
* `describe(self) -> str` — строка `"имя: n элементов"`, где `n` — количество
  элементов в `items`.

## Примеры

```python
Registry.created  # 0

a = Registry("первый")
b = Registry("второй")
Registry.created  # 2
a.created  # 2 — то же поле, прочитанное через экземпляр

a.add("x")
a.items  # ["x"]
b.items  # []

a.describe()  # "первый: 1 элементов"
b.describe()  # "второй: 0 элементов"
```
