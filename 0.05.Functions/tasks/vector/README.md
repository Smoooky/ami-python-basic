# vector

Собственные классы нужны, чтобы значение и операции над ним жили вместе.
Двумерный вектор — минимальный пример: у него есть две координаты, длина и
понятие равенства.

Реализовать класс `Vector`.

## Что должно быть в классе

* конструктор `__init__(self, x: float, y: float)` — сохраняет координаты в
  полях `x` и `y`;
* метод `length(self) -> float` — длина вектора, корень из суммы квадратов
  координат;
* метод `plus(self, other: "Vector") -> "Vector"` — возвращает **новый** вектор,
  сумму координат; исходные векторы не меняются;
* равенство: два вектора равны, когда совпадают обе координаты. Сравнение с
  объектом другого типа даёт `False`, а не ошибку;
* хешируемость: вектор можно положить в множество и использовать ключом
  словаря.

## Про равенство и хеш

Эти два свойства связаны: равные объекты обязаны иметь равный хеш, иначе
множество и словарь начнут терять элементы. Если определить только `__eq__`,
класс перестанет быть хешируемым — Python снимает хеш по умолчанию, чтобы не
допустить рассогласования.

Координаты вектора не меняются после создания, поэтому хеш можно построить из
них.

## Пример использования

```python
a = Vector(3, 4)
a.length()  # 5.0
a.plus(Vector(1, 1))  # Vector(4, 5)
a == Vector(3, 4)  # True
a == "не вектор"  # False
len({Vector(1, 1), Vector(1, 1)})  # 1
```
