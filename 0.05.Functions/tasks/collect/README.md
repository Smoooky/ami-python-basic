# collect

Функция накапливает значения в списке: получает очередное значение и список, в
который его нужно добавить. Если список не передан, создаётся новый.

Реализовать функцию
`collect(value: int, into: list[int] | None = None) -> list[int]`, которая
добавляет `value` в конец `into` и возвращает получившийся список.

## Поведение без аргумента into

Повторные вызовы **без** аргумента `into` не должны видеть результатов друг
друга: каждый такой вызов начинает с пустого списка.

```python
collect(1)  # [1]
collect(2)  # [2]   а не [1, 2]
```

Значение по умолчанию вычисляется один раз, в момент объявления функции, а не
при каждом вызове. Изменяемый объект, записанный в умолчание, жил бы между
вызовами и накапливал изменения — поэтому в сигнатуре стоит `None`.

## Сигнатура

```python
def collect(value: int, into: list[int] | None = None) -> list[int]: ...
```

## Примеры

```python
collect(1)  # [1]
collect(3, [1, 2])  # [1, 2, 3]
target = [1]
collect(2, target)  # [1, 2]
target  # [1, 2] — переданный список меняется на месте
```

Если список передан, он дополняется на месте и возвращается он же. Если не
передан — возвращается новый список.
