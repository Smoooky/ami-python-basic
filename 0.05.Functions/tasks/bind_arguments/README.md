# bind_arguments

Когда программа вызывает функцию, интерпретатор сопоставляет переданные
аргументы с параметрами из объявления: раскладывает позиционные по порядку,
именованные — по именам, а незаполненное берёт из значений по умолчанию.

Требуется повторить это сопоставление.

## Как описана сигнатура

Параметры приходят списком пар «имя, вид»:

| Вид | Что означает |
|---|---|
| `"p"` | только позиционный — до разделителя `/` в объявлении |
| `"n"` | обычный — можно передать и позиционно, и по имени |
| `"k"` | только именованный — после разделителя `*` |

Порядок в списке совпадает с порядком в объявлении: сначала все `"p"`, затем
все `"n"`, затем все `"k"`.

Отдельно приходит словарь `defaults` — значения по умолчанию для тех
параметров, у которых они есть.

## Правила сопоставления

1. Позиционные аргументы заполняют параметры видов `"p"` и `"n"` по порядку:
   первый аргумент — первому такому параметру, второй — второму.
2. Именованные аргументы заполняют параметры по имени. Параметру вида `"p"`
   так значение передать нельзя — его имя в вызове не участвует.
3. Параметры, не заполненные ни тем, ни другим способом, берут значение из
   `defaults`.

Вызов корректен: аргументов не больше, чем параметров, один параметр не
заполняется дважды, и у всех незаполненных параметров есть значение по
умолчанию.

## Сигнатура

```python
from typing import Any


def bind_arguments(
    parameters: list[tuple[str, str]],
    defaults: dict[str, Any],
    args: list[Any],
    kwargs: dict[str, Any],
) -> dict[str, Any]: ...
```

## Примеры

Объявлению `def f(x, /, y, *, z=0)` соответствует список
`[("x", "p"), ("y", "n"), ("z", "k")]`.

```python
parameters = [("x", "p"), ("y", "n"), ("z", "k")]

bind_arguments(parameters, {"z": 0}, [1, 2], {})
# {"x": 1, "y": 2, "z": 0}

bind_arguments(parameters, {"z": 0}, [1], {"y": 5, "z": 9})
# {"x": 1, "y": 5, "z": 9}

bind_arguments([("a", "n")], {"a": 42}, [], {})
# {"a": 42}
```

Во втором примере `y` передан по имени, хотя мог бы позиционно, — обычный
параметр допускает оба способа.

Возвращается словарь «имя параметра — значение», в нём должны быть **все**
параметры из объявления.
